# 如何制作技能栏

## 核心挑战

在 Minecraft 原版数据包中制作技能栏面临几个核心挑战：
1. **无原生 UI 系统**：原版没有自定义 GUI 的 API，只能利用现有机制模拟
2. **实时交互困难**：玩家选择技能后需要即时反馈，但原版交互机制有限
3. **状态持久化**：技能冷却、当前选中技能等状态需要跨游戏会话保存
4. **版本兼容性**：不同版本对物品组件、NBT 格式的支持差异很大

## 方案一：基于物品栏的技能栏（推荐，1.20.5+）

### 原理

利用玩家的快捷栏（hotbar）作为技能栏的视觉载体。每个技能对应一个特殊物品，玩家通过切换快捷栏物品来选择技能。通过 `inventory_changed` 进度监听物品栏变化，检测玩家当前选中的技能。

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    advancement/
      skillbar/
        select.json          # 监听技能选择
    function/
      skillbar/
        init.mcfunction      # 初始化技能栏
        tick.mcfunction      # 每 tick 检测
        select.mcfunction    # 技能选择处理
        clear.mcfunction     # 清除技能物品
        skills/
          fireball.mcfunction    # 火球技能
          heal.mcfunction        # 治疗技能
    item_modifier/
      skillbar/
        tag_skill.json       # 给物品打技能标记
    predicate/
      skillbar/
        is_skill.json        # 检测是否为技能物品
```

#### 1. 初始化技能物品

`data/<namespace>/item_modifier/skillbar/tag_skill.json`
```json
{
  "function": "minecraft:set_custom_data",
  "tag": "{<namespace>:{skill_id:\"fireball\",cooldown:0}}"
}
```

#### 2. 技能选择监听进度

`data/<namespace>/advancement/skillbar/select.json`
```json
{
  "criteria": {
    "skill_selected": {
      "trigger": "minecraft:inventory_changed",
      "conditions": {
        "player": [
          {
            "condition": "minecraft:entity_properties",
            "entity": "this",
            "predicate": {
              "equipment": {
                "mainhand": {
                  "items": ["minecraft:stick"],
                  "predicates": {
                    "minecraft:custom_data": "{<namespace>:{skill_id:\"fireball\"}}"
                  }
                }
              }
            }
          }
        ]
      }
    }
  },
  "rewards": {
    "function": "<namespace>:skillbar/select"
  }
}
```

#### 3. 技能选择处理函数

`data/<namespace>/function/skillbar/select.mcfunction`
```mcfunction
# 获取当前主手物品的技能 ID
execute store result score @s skill_id run data get entity @s Inventory[{Slot:-106b}].components."minecraft:custom_data".<namespace>.skill_id

# 根据技能 ID 执行对应逻辑
execute if score @s skill_id matches 0 run function <namespace>:skillbar/skills/fireball
execute if score @s skill_id matches 1 run function <namespace>:skillbar/skills/heal

# 清除技能物品（防止被使用）
function <namespace>:skillbar/clear

# 重新给予技能物品
function <namespace>:skillbar/init

# 撤销进度，允许下次触发
advancement revoke @s only <namespace>:skillbar/select
```

#### 4. 技能物品清除

`data/<namespace>/function/skillbar/clear.mcfunction`
```mcfunction
# 清除所有技能物品
clear @s minecraft:stick{<namespace>:{skill_id:"fireball"}}
clear @s minecraft:stick{<namespace>:{skill_id:"heal"}}
```

#### 5. 技能实现示例

`data/<namespace>/function/skillbar/skills/fireball.mcfunction`
```mcfunction
# 发射火球
summon minecraft:fireball ~ ~1 ~ {Motion:[0.0,0.0,0.0],power:[0.0,0.0,0.0],direction:[0.0,0.0,0.0]}

# 设置冷却（使用 scoreboard）
scoreboard players set @s skill_cooldown 100
```

### 陷阱与注意事项

1. **物品堆叠问题**：技能物品不能堆叠，否则 `clear` 命令会清除所有同类物品。建议使用不可堆叠的物品（如剑、工具）。
2. **创造模式玩家**：创造模式下物品不会被消耗，需要额外处理。
3. **物品 NBT 匹配**：`clear` 命令的 NBT 匹配在 1.20.5+ 使用 `components` 格式，旧版本使用 `tag` 格式。
4. **性能开销**：每个 tick 检测所有玩家的物品栏变化，开销中等。建议只在玩家切换物品时触发，而不是每 tick 检测。

## 方案二：基于 Bossbar 的技能栏（1.16+）

### 原理

利用 Bossbar 的文本显示和进度条来模拟技能栏。通过 `title` 命令显示技能名称，Bossbar 的进度表示冷却状态。玩家通过特定按键（如 F 键）切换技能，通过右键使用技能。

### 完整实现

#### 1. 创建 Bossbar

`data/<namespace>/function/skillbar/init.mcfunction`
```mcfunction
# 创建技能栏 Bossbar
bossbar add <namespace>:skillbar {"text":"技能栏","color":"gold"}
bossbar set <namespace>:skillbar max 3
bossbar set <namespace>:skillbar value 0
bossbar set <namespace>:skillbar color green
bossbar set <namespace>:skillbar style notched_6

# 为每个玩家显示
bossbar set <namespace>:skillbar players @a
```

#### 2. 技能切换检测

`data/<namespace>/function/skillbar/tick.mcfunction`
```mcfunction
# 检测 F 键按下（使用物品交换标记法，详见 F 键检测条目）
execute if predicate <namespace>:skillbar/fkey_pressed run function <namespace>:skillbar/switch

# 检测右键使用
execute as @a[scores={skill_cooldown=0}] at @s if predicate <namespace>:skillbar/right_click run function <namespace>:skillbar/use
```

#### 3. 技能切换

`data/<namespace>/function/skillbar/switch.mcfunction`
```mcfunction
# 切换当前技能
scoreboard players add @s current_skill 1
scoreboard players operation @s current_skill %= @s max_skill

# 更新 Bossbar 显示
execute store result bossbar <namespace>:skillbar value run scoreboard players get @s current_skill

# 显示技能名称
execute if score @s current_skill matches 0 run title @s actionbar {"text":"🔥 火球术","color":"red"}
execute if score @s current_skill matches 1 run title @s actionbar {"text":"💚 治疗术","color":"green"}
execute if score @s current_skill matches 2 run title @s actionbar {"text":"🛡️ 护盾术","color":"blue"}
```

#### 4. 技能使用

`data/<namespace>/function/skillbar/use.mcfunction`
```mcfunction
# 根据当前技能执行
execute if score @s current_skill matches 0 run function <namespace>:skillbar/skills/fireball
execute if score @s current_skill matches 1 run function <namespace>:skillbar/skills/heal
execute if score @s current_skill matches 2 run function <namespace>:skillbar/skills/shield

# 设置冷却
scoreboard players set @s skill_cooldown 100
```

### 陷阱与注意事项

1. **Bossbar 数量限制**：每个玩家最多只能看到 1 个 Bossbar（1.16-1.20）或 2 个（1.20.5+），如果已有其他 Bossbar 会冲突。
2. **F 键检测可靠性**：F 键检测在物品相同时会失效，详见 F 键检测条目。
3. **右键检测**：右键检测需要配合 `used_item` 进度或 `item_used_on_block` 触发，不能直接检测右键动作。
4. **多玩家支持**：Bossbar 是全局的，需要为每个玩家单独管理状态。

## 方案三：基于 Scoreboard 和 Title 的技能栏（1.13+，最兼容）

### 原理

完全不依赖物品，只使用 scoreboard 存储技能状态，通过 `title` 命令在 actionbar 显示技能信息。玩家通过聊天命令或特定按键切换技能。

### 完整实现

#### 1. 初始化

`data/<namespace>/function/skillbar/init.mcfunction`
```mcfunction
# 创建计分板
scoreboard objectives add skill_id dummy
scoreboard objectives add skill_cooldown dummy
scoreboard objectives add max_skill dummy

# 设置初始值
scoreboard players set @a skill_id 0
scoreboard players set @a max_skill 3
scoreboard players set @a skill_cooldown 0
```

#### 2. 显示技能栏

`data/<namespace>/function/skillbar/display.mcfunction`
```mcfunction
# 显示当前技能
execute if score @s skill_id matches 0 run title @s actionbar [{"text":"[","color":"gray"},{"text":"🔥","color":"red"},{"text":"] 火球术","color":"white"}]
execute if score @s skill_id matches 1 run title @s actionbar [{"text":"[","color":"gray"},{"text":"💚","color":"green"},{"text":"] 治疗术","color":"white"}]
execute if score @s skill_id matches 2 run title @s actionbar [{"text":"[","color":"gray"},{"text":"🛡️","color":"blue"},{"text":"] 护盾术","color":"white"}]

# 显示冷却状态
execute if score @s skill_cooldown > 0 run title @s actionbar [{"text":"⏳ 冷却中: ","color":"red"},{"text":"","score":{"name":"@s","objective":"skill_cooldown"}}]
```

#### 3. 技能切换命令

`data/<namespace>/function/skillbar/switch.mcfunction`
```mcfunction
# 通过命令切换技能
# 用法：/function <namespace>:skillbar/switch {skill:1}
scoreboard players set @s skill_id $(skill)
function <namespace>:skillbar/display
```

#### 4. 技能使用

`data/<namespace>/function/skillbar/use.mcfunction`
```mcfunction
# 检测冷却
execute if score @s skill_cooldown > 0 run tellraw @s {"text":"技能冷却中！","color":"red"}
execute if score @s skill_cooldown > 0 run return fail

# 执行技能
execute if score @s skill_id matches 0 run function <namespace>:skillbar/skills/fireball
execute if score @s skill_id matches 1 run function <namespace>:skillbar/skills/heal
execute if score @s skill_id matches 2 run function <namespace>:skillbar/skills/shield

# 设置冷却
scoreboard players set @s skill_cooldown 100
```

### 陷阱与注意事项

1. **无视觉反馈**：玩家无法直观看到技能栏，只能通过 actionbar 文字了解。
2. **命令依赖**：切换技能需要执行命令，不适合快速切换。
3. **冷却显示**：actionbar 会被其他消息覆盖，需要持续刷新。
4. **多语言支持**：文字显示需要处理不同语言环境。

## 方案对比

| 特性 | 物品栏方案 | Bossbar 方案 | Scoreboard 方案 |
|------|-----------|-------------|----------------|
| **最低版本** | 1.20.5 | 1.16 | 1.13 |
| **视觉反馈** | 优秀（物品图标） | 良好（进度条） | 一般（文字） |
| **交互方式** | 物品切换 | 按键切换 | 命令切换 |
| **冷却显示** | 物品耐久度 | Bossbar 进度 | 文字数字 |
| **性能开销** | 中等 | 较低 | 低 |
| **多玩家支持** | 原生支持 | 需额外管理 | 原生支持 |
| **创造模式兼容** | 需特殊处理 | 正常 | 正常 |
| **实现复杂度** | 高 | 中 | 低 |
| **可扩展性** | 高 | 中 | 中 |

## 推荐方案

- **1.20.5+ 新项目**：使用物品栏方案，体验最好
- **1.16-1.20 兼容项目**：使用 Bossbar 方案
- **1.13-1.15 旧版本**：使用 Scoreboard 方案
- **需要快速原型**：使用 Scoreboard 方案，后期可迁移
