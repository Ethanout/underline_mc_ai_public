# 如何制作对话系统

## 核心挑战

在 Minecraft 原版数据包中制作对话系统，面临以下核心挑战：
1. **无原生 UI 支持**：原版没有 NPC 对话窗口、对话框或文本输入框
2. **玩家交互方式有限**：只能通过右键实体、按键、物品使用等间接方式触发对话
3. **文本显示限制**：聊天栏、标题、Bossbar、物品 lore 是仅有的文本显示渠道
4. **状态管理复杂**：对话树、分支、条件判断需要复杂的 scoreboard 和 storage 管理

## 方案一：基于 Bossbar 的对话系统（推荐，1.13+）

### 原理

利用 Bossbar 的文本显示功能，将对话内容显示在屏幕上方。通过 `bossbar set <id> name` 更新对话文本，使用 `bossbar set <id> players` 控制可见性。对话树通过 scoreboard 和 storage 管理状态。

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    function/
      dialog/
        init.mcfunction
        tick.mcfunction
        show.mcfunction
        hide.mcfunction
        next.mcfunction
        prev.mcfunction
        select_option.mcfunction
        nodes/
          node_1.mcfunction
          node_2.mcfunction
    bossbar/
      dialog.json
```

#### 1. 初始化 Bossbar (Load)
`data/<namespace>/function/dialog/init.mcfunction`
```mcfunction
# 创建对话 Bossbar
bossbar add <namespace>:dialog ""

# 设置样式（可选）
bossbar set <namespace>:dialog color white
bossbar set <namespace>:dialog style notched_6

# 初始化玩家对话状态
scoreboard objectives add <namespace>.dialog_state dummy
scoreboard objectives add <namespace>.dialog_node dummy
scoreboard objectives add <namespace>.dialog_option dummy

# 初始化 Storage
data modify storage <namespace>:dialog current_node set value ""
data modify storage <namespace>:dialog options set value []
data modify storage <namespace>:dialog speaker set value ""
```

#### 2. 显示对话
`data/<namespace>/function/dialog/show.mcfunction`
```mcfunction
# 设置当前对话节点
scoreboard players set @s <namespace>.dialog_state 1

# 根据节点 ID 加载对话内容
execute if score @s <namespace>.dialog_node matches 1 run function <namespace>:dialog/nodes/node_1
execute if score @s <namespace>.dialog_node matches 2 run function <namespace>:dialog/nodes/node_2

# 显示 Bossbar
bossbar set <namespace>:dialog players @s
```

#### 3. 对话节点示例
`data/<namespace>/function/dialog/nodes/node_1.mcfunction`
```mcfunction
# 设置对话文本（使用 JSON 文本组件）
bossbar set <namespace>:dialog name {"text":"村民：你好，旅行者！","color":"gold"}

# 设置选项（存储在 Storage 中）
data modify storage <namespace>:dialog options set value [
  {"id":1,"text":"你好！","next_node":2},
  {"id":2,"text":"你是谁？","next_node":3},
  {"id":3,"text":"再见。","next_node":0}
]

# 显示选项（通过 tellraw 或物品 lore）
tellraw @s [{"text":"\n[1] 你好！","color":"green","clickEvent":{"action":"run_command","value":"/scoreboard players set @s <namespace>.dialog_option 1"}}]
tellraw @s [{"text":"[2] 你是谁？","color":"green","clickEvent":{"action":"run_command","value":"/scoreboard players set @s <namespace>.dialog_option 2"}}]
tellraw @s [{"text":"[3] 再见。","color":"red","clickEvent":{"action":"run_command","value":"/scoreboard players set @s <namespace>.dialog_option 3"}}]
```

#### 4. 处理选项选择
`data/<namespace>/function/dialog/select_option.mcfunction`
```mcfunction
# 获取玩家选择的选项
scoreboard players operation @s <namespace>.dialog_option = @s <namespace>.dialog_option

# 根据选项跳转到下一个节点
execute if score @s <namespace>.dialog_option matches 1 run scoreboard players set @s <namespace>.dialog_node 2
execute if score @s <namespace>.dialog_option matches 2 run scoreboard players set @s <namespace>.dialog_node 3
execute if score @s <namespace>.dialog_option matches 3 run scoreboard players set @s <namespace>.dialog_node 0

# 重置选项
scoreboard players set @s <namespace>.dialog_option 0

# 显示下一个节点
execute if score @s <namespace>.dialog_node matches 0 run function <namespace>:dialog/hide
execute unless score @s <namespace>.dialog_node matches 0 run function <namespace>:dialog/show
```

#### 5. 隐藏对话
`data/<namespace>/function/dialog/hide.mcfunction`
```mcfunction
# 隐藏 Bossbar
bossbar set <namespace>:dialog players @s

# 重置状态
scoreboard players set @s <namespace>.dialog_state 0
scoreboard players set @s <namespace>.dialog_node 0
scoreboard players set @s <namespace>.dialog_option 0
```

#### 6. Tick 函数（可选，用于自动触发）
`data/<namespace>/function/dialog/tick.mcfunction`
```mcfunction
# 检测玩家右键 NPC 实体（需要配合 advancement）
execute as @a[predicate=<namespace>:right_click_npc] at @s run function <namespace>:dialog/show
```

### 陷阱与注意事项

1. **Bossbar 数量限制**：每个玩家最多同时显示 1 个 Bossbar（1.16+ 改为无限制，但建议只用一个）
2. **文本长度限制**：Bossbar 名称最大长度约 64 字符（含 JSON 格式），长文本会被截断
3. **选项交互**：使用 `clickEvent` 的 `run_command` 需要玩家有命令权限（2 级），在生存模式下不可用
4. **多玩家冲突**：Bossbar 是全局资源，需要为每个玩家单独管理状态
5. **性能开销**：每次对话更新都需要执行多个命令，但频率低，开销较低

## 方案二：基于物品 Lore 的对话系统（1.14+）

### 原理

利用物品的 lore（描述文本）显示对话内容。玩家手持"对话书"或"对话卷轴"时，通过查看物品 lore 阅读对话。使用 `item modifier` 动态修改物品的 lore。

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    function/
      dialog/
        give_book.mcfunction
        update_lore.mcfunction
        next_page.mcfunction
        close.mcfunction
    item_modifier/
      dialog/
        set_lore.json
        clear_lore.json
    advancement/
      dialog/
        open_book.json
```

#### 1. 给予对话书
`data/<namespace>/function/dialog/give_book.mcfunction`
```mcfunction
# 给予玩家对话书
give @s minecraft:written_book{
  title:'{"text":"对话记录"}',
  author:'{"text":"系统"}',
  pages:['["",{"text":"对话系统","bold":true,"color":"gold"}]'],
  custom_data:{<namespace>:{dialog_book:1b}}
}
```

#### 2. 更新对话内容
`data/<namespace>/function/dialog/update_lore.mcfunction`
```mcfunction
# 使用 item modifier 更新物品 lore
item modify entity @s weapon.mainhand <namespace>:dialog/set_lore

# 设置当前对话内容到 Storage
data modify storage <namespace>:dialog current_text set value '{"text":"村民：你好，旅行者！","color":"gold"}'
```

`data/<namespace>/item_modifier/dialog/set_lore.json`
```json
{
  "function": "minecraft:set_lore",
  "entity": "this",
  "lore": [
    {"text":"村民：你好，旅行者！","color":"gold","italic":false},
    {"text":"","italic":false},
    {"text":"[1] 你好！","color":"green","italic":false},
    {"text":"[2] 你是谁？","color":"green","italic":false},
    {"text":"[3] 再见。","color":"red","italic":false}
  ]
}
```

#### 3. 翻页/选择
`data/<namespace>/function/dialog/next_page.mcfunction`
```mcfunction
# 检测玩家手持对话书
execute if items entity @s weapon.mainhand *[custom_data~{<namespace>:{dialog_book:1b}}] run {
  # 更新 lore 到下一页
  item modify entity @s weapon.mainhand <namespace>:dialog/set_lore
}
```

### 陷阱与注意事项

1. **物品堆叠问题**：修改 lore 后物品无法与同类物品堆叠
2. **创造模式问题**：创造模式下修改物品可能导致物品复制或丢失
3. **交互方式**：玩家需要打开物品栏查看 lore，交互不够直观
4. **版本要求**：`item modify` 命令需要 1.14+
5. **性能开销**：每次更新都需要修改物品 NBT，开销较低

## 方案三：基于聊天栏的对话系统（1.13+）

### 原理

利用 `tellraw` 命令在聊天栏显示对话文本，配合 `clickEvent` 实现选项选择。使用 `scoreboard` 管理对话状态和分支。

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    function/
      dialog/
        start.mcfunction
        show_text.mcfunction
        show_options.mcfunction
        handle_choice.mcfunction
        end.mcfunction
    advancement/
      dialog/
        trigger_choice.json
```

#### 1. 开始对话
`data/<namespace>/function/dialog/start.mcfunction`
```mcfunction
# 初始化对话状态
scoreboard players set @s <namespace>.dialog_active 1
scoreboard players set @s <namespace>.dialog_node 1

# 显示对话文本
tellraw @s [{"text":"\n=== 对话开始 ===\n","color":"gold","bold":true}]
function <namespace>:dialog/show_text
```

#### 2. 显示对话文本
`data/<namespace>/function/dialog/show_text.mcfunction`
```mcfunction
# 根据节点显示不同文本
execute if score @s <namespace>.dialog_node matches 1 run tellraw @s [{"text":"村民：","color":"gold"},{"text":"你好，旅行者！","color":"white"}]
execute if score @s <namespace>.dialog_node matches 2 run tellraw @s [{"text":"村民：","color":"gold"},{"text":"我是这个村庄的守卫。","color":"white"}]
execute if score @s <namespace>.dialog_node matches 3 run tellraw @s [{"text":"村民：","color":"gold"},{"text":"再见，一路顺风！","color":"white"}]

# 显示选项
function <namespace>:dialog/show_options
```

#### 3. 显示选项
`data/<namespace>/function/dialog/show_options.mcfunction`
```mcfunction
# 节点 1 的选项
execute if score @s <namespace>.dialog_node matches 1 run {
  tellraw @s [{"text":"\n[1] ","color":"green"},{"text":"你好！","color":"white","clickEvent":{"action":"run_command","value":"/trigger <namespace>.dialog_choice set 1"}}]
  tellraw @s [{"text":"[2] ","color":"green"},{"text":"你是谁？","color":"white","clickEvent":{"action":"run_command","value":"/trigger <namespace>.dialog_choice set 2"}}]
  tellraw @s [{"text":"[3] ","color":"red"},{"text":"再见。","color":"white","clickEvent":{"action":"run_command","value":"/trigger <namespace>.dialog_choice set 3"}}]
}

# 节点 2 的选项
execute if score @s <namespace>.dialog_node matches 2 run {
  tellraw @s [{"text":"\n[1] ","color":"green"},{"text":"能告诉我更多吗？","color":"white","clickEvent":{"action":"run_command","value":"/trigger <namespace>.dialog_choice set 4"}}]
  tellraw @s [{"text":"[2] ","color":"red"},{"text":"再见。","color":"white","clickEvent":{"action":"run_command","value":"/trigger <namespace>.dialog_choice set 3"}}]
}
```

#### 4. 处理选择（通过 advancement 触发）
`data/<namespace>/advancement/dialog/trigger_choice.json`
```json
{
  "criteria": {
    "choice_made": {
      "trigger": "minecraft:tick"
    }
  },
  "rewards": {
    "function": "<namespace>:dialog/handle_choice"
  }
}
```

`data/<namespace>/function/dialog/handle_choice.mcfunction`
```mcfunction
# 获取玩家选择
scoreboard players operation @s <namespace>.dialog_choice = @s <namespace>.dialog_choice

# 根据选择跳转节点
execute if score @s <namespace>.dialog_choice matches 1 run scoreboard players set @s <namespace>.dialog_node 2
execute if score @s <namespace>.dialog_choice matches 2 run scoreboard players set @s <namespace>.dialog_node 3
execute if score @s <namespace>.dialog_choice matches 3 run function <namespace>:dialog/end
execute if score @s <namespace>.dialog_choice matches 4 run scoreboard players set @s <namespace>.dialog_node 4

# 重置选择
scoreboard players set @s <namespace>.dialog_choice 0

# 继续对话
execute unless score @s <namespace>.dialog_active matches 0 run function <namespace>:dialog/show_text
```

#### 5. 结束对话
`data/<namespace>/function/dialog/end.mcfunction`
```mcfunction
# 显示结束文本
tellraw @s [{"text":"\n=== 对话结束 ===\n","color":"gold","bold":true}]

# 重置状态
scoreboard players set @s <namespace>.dialog_active 0
scoreboard players set @s <namespace>.dialog_node 0
scoreboard players set @s <namespace>.dialog_choice 0
```

### 陷阱与注意事项

1. **命令权限**：`trigger` 命令需要玩家有 2 级权限，在生存模式下默认不可用
2. **聊天栏污染**：对话文本会混入其他聊天信息，影响体验
3. **历史记录**：玩家可以滚动聊天栏查看历史对话，但长对话会刷屏
4. **多玩家同步**：每个玩家的对话状态独立，但聊天栏是全局的
5. **性能开销**：每次对话更新需要执行多个 `tellraw` 命令，开销较低

## 方案四：基于 Title 的对话系统（1.11+）

### 原理

利用 `title` 命令在屏幕中央显示对话文本，配合 `subtitle` 显示选项。使用 `scoreboard` 管理对话状态。

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    function/
      dialog/
        show_title.mcfunction
        show_subtitle.mcfunction
        next.mcfunction
        close.mcfunction
```

#### 1. 显示对话
`data/<namespace>/function/dialog/show_title.mcfunction`
```mcfunction
# 显示对话文本（主标题）
title @s title {"text":"村民：你好，旅行者！","color":"gold"}

# 显示选项（副标题）
title @s subtitle {"text":"[1] 你好！  [2] 你是谁？  [3] 再见。","color":"green"}

# 设置显示时间
title @s times 10 100 10
```

#### 2. 处理选择（通过按键检测）
`data/<namespace>/function/dialog/next.mcfunction`
```mcfunction
# 检测玩家按键（需要配合 predicate）
execute if predicate <namespace>:dialog/key_1 run scoreboard players set @s <namespace>.dialog_node 2
execute if predicate <namespace>:dialog/key_2 run scoreboard players set @s <namespace>.dialog_node 3
execute if predicate <namespace>:dialog/key_3 run function <namespace>:dialog/close

# 更新显示
function <namespace>:dialog/show_title
```

### 陷阱与注意事项

1. **文本长度限制**：Title 文本最大长度约 32 字符，长文本会被截断
2. **显示时间**：Title 有固定的显示时间，不适合长对话
3. **按键检测**：需要复杂的 predicate 或 advancement 来检测按键
4. **交互方式**：玩家无法直接点击选项，只能通过按键选择
5. **性能开销**：Title 命令开销极低，但频繁更新可能影响体验

## 方案对比

| 方案 | 版本要求 | 交互方式 | 文本长度 | 多玩家支持 | 性能开销 | 适用场景 |
|------|---------|---------|---------|-----------|---------|---------|
| Bossbar | 1.13+ | 命令/按键 | 中等(64字符) | 好 | 低 | 简单对话、NPC交互 |
| 物品Lore | 1.14+ | 物品栏查看 | 长(多行) | 好 | 低 | 书籍、卷轴类对话 |
| 聊天栏 | 1.13+ | 点击选项 | 长(多行) | 一般 | 低 | 复杂对话树、RPG |
| Title | 1.11+ | 按键 | 短(32字符) | 好 | 极低 | 快速提示、简单对话 |

## 推荐方案

对于大多数 RPG 数据包，推荐使用 **方案一（Bossbar）** 作为主要对话系统，配合 **方案三（聊天栏）** 处理复杂对话树。Bossbar 方案在视觉上最接近传统 RPG 的对话界面，且对多玩家支持最好。
