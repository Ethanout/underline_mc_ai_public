# 如何做圆螺旋波浪轨迹

## 问题分析

在 Minecraft 数据包中实现圆螺旋波浪轨迹，核心挑战在于：
1. 原版没有直接的三角函数支持（1.20.5 之前）
2. 需要同时控制多个实体的位置形成波浪效果
3. 需要处理不同版本间的命令差异

## 方案一：基于 scoreboard 的三角函数计算（1.13+，推荐）

### 原理

利用 `scoreboard` 存储角度值，通过预计算或近似计算生成螺旋轨迹。核心思路：
- 使用 `scoreboard` 存储角度（0-360度）
- 通过 `execute store` 将角度转换为弧度
- 使用泰勒展开或查表法计算 sin/cos 值
- 结合时间变量生成波浪效果

### 完整实现

#### 1. 初始化 (load)

```mcfunction
# load.mcfunction
scoreboard objectives add angle dummy
scoreboard objectives add time dummy
scoreboard objectives add sin_val dummy
scoreboard objectives add cos_val dummy
scoreboard objectives add radius dummy
scoreboard objectives add height dummy

# 初始化角度步长（每 tick 增加 5 度）
scoreboard players set #step angle 5
# 初始化半径
scoreboard players set #radius radius 10
# 初始化高度增量
scoreboard players set #height_step height 1
```

#### 2. 主循环 (tick)

```mcfunction
# tick.mcfunction
# 更新所有实体的角度
execute as @e[tag=spiral_entity] at @s run function namespace:spiral/update

# 更新全局时间
scoreboard players add #time time 1
```

#### 3. 实体更新函数

```mcfunction
# namespace:spiral/update.mcfunction
# 获取当前角度
scoreboard players operation @s angle += #step angle
scoreboard players operation @s angle %= 360

# 计算 sin 值（使用查表法）
function namespace:spiral/sin_lookup

# 计算 cos 值（使用查表法，cos = sin(angle + 90)）
scoreboard players operation #temp angle = @s angle
scoreboard players add #temp angle 90
scoreboard players operation #temp angle %= 360
function namespace:spiral/sin_lookup_temp

# 计算位置偏移
# x = radius * cos(angle)
scoreboard players operation @s x_pos = #radius radius
scoreboard players operation @s x_pos *= #cos_val sin_val
scoreboard players operation @s x_pos /= 1000

# z = radius * sin(angle)
scoreboard players operation @s z_pos = #radius radius
scoreboard players operation @s z_pos *= @s sin_val
scoreboard players operation @s z_pos /= 1000

# y = height * sin(time + angle_offset)
scoreboard players operation #temp height = #height_step height
scoreboard players operation #temp height *= @s sin_val
scoreboard players operation #temp height /= 1000

# 应用位置
execute store result entity @s Pos[0] double 0.001 run scoreboard players get @s x_pos
execute store result entity @s Pos[1] double 0.001 run scoreboard players get #temp height
execute store result entity @s Pos[2] double 0.001 run scoreboard players get @s z_pos
```

#### 4. sin 查表函数

```mcfunction
# namespace:spiral/sin_lookup.mcfunction
# 使用二分查找或条件判断实现 sin 值查表
# 这里使用简化版本，实际应使用更精确的查表
execute if score @s angle matches 0 run scoreboard players set @s sin_val 0
execute if score @s angle matches 30 run scoreboard players set @s sin_val 500
execute if score @s angle matches 60 run scoreboard players set @s sin_val 866
execute if score @s angle matches 90 run scoreboard players set @s sin_val 1000
# ... 其他角度值
```

### 陷阱与注意事项

1. **精度问题**：scoreboard 只能存储整数，需要放大 1000 倍来模拟小数
2. **性能开销**：每个实体每 tick 都需要执行多次 scoreboard 操作，开销较高
3. **查表法限制**：角度步长需要是查表角度的整数倍，否则会产生跳跃
4. **版本兼容**：1.13+ 可用，但 1.20.5 后 `execute store` 语法有变化

## 方案二：基于实体旋转的近似螺旋（1.13+，简单方案）

### 原理

利用实体的旋转角度（Yaw）和向前移动来模拟螺旋轨迹。通过不断改变实体的 Yaw 并向前移动，形成近似螺旋效果。

### 完整实现

```mcfunction
# namespace:spiral/simple_tick.mcfunction
# 每 tick 旋转实体并向前移动
execute as @e[tag=spiral_entity] at @s run function namespace:spiral/move

# namespace:spiral/move.mcfunction
# 旋转实体
tp @s ~ ~ ~ ~5 ~

# 向前移动（使用实体朝向）
execute at @s run tp @s ^ ^ ^0.5

# 添加垂直波浪
execute store result entity @s Pos[1] double 0.01 run data get entity @s Pos[1] 1
execute at @s run tp @s ~ ~ ~ ~ ~
```

### 陷阱与注意事项

1. **精度低**：只能形成近似螺旋，无法精确控制半径和高度
2. **实体碰撞**：多个实体可能互相碰撞导致轨迹混乱
3. **性能**：`tp` 命令开销较低，但大量实体时仍需注意

## 方案三：基于 advancement 的定时触发（1.20.5+，推荐）

### 原理

利用 1.20.5 新增的 `minecraft:tick` 触发器和 `execute on` 功能，实现更精确的定时控制。

### 完整实现

#### 1. 创建 advancement

```json
{
  "criteria": {
    "tick": {
      "trigger": "minecraft:tick"
    }
  },
  "rewards": {
    "function": "namespace:spiral/tick_handler"
  }
}
```

#### 2. 处理函数

```mcfunction
# namespace:spiral/tick_handler.mcfunction
# 使用 storage 存储角度和时间
data modify storage namespace:spiral angle set value 0
data modify storage namespace:spiral time set value 0

# 更新所有螺旋实体
execute as @e[tag=spiral_entity] at @s run function namespace:spiral/update_v2

# 更新全局角度和时间
data modify storage namespace:spiral angle set value 5
data modify storage namespace:spiral time set value 1
```

#### 3. 更新函数（使用宏）

```mcfunction
# namespace:spiral/update_v2.mcfunction
$execute store result entity @s Pos[0] double 0.01 run data get storage namespace:spiral angle 1
$execute store result entity @s Pos[1] double 0.01 run data get storage namespace:spiral time 1
$execute store result entity @s Pos[2] double 0.01 run data get storage namespace:spiral angle 1
```

### 陷阱与注意事项

1. **版本要求**：仅 1.20.5+ 可用
2. **宏的使用**：需要正确设置宏参数
3. **性能**：advancement 触发有延迟，不适合高频更新

## 方案四：基于粒子效果的视觉螺旋（1.13+，纯视觉方案）

### 原理

使用粒子命令模拟螺旋轨迹，不涉及实体移动，适合装饰效果。

### 完整实现

```mcfunction
# namespace:spiral/particle.mcfunction
# 生成螺旋粒子效果
execute at @a[limit=1] run particle minecraft:end_rod ^ ^1 ^ 0 0 0 0 10 force
execute at @a[limit=1] run particle minecraft:end_rod ^0.5 ^1.5 ^0.5 0 0 0 0 5 force
execute at @a[limit=1] run particle minecraft:end_rod ^-0.5 ^2 ^-0.5 0 0 0 0 5 force
```

### 陷阱与注意事项

1. **纯视觉**：无法用于实体移动
2. **性能**：粒子数量过多会导致卡顿
3. **视角依赖**：粒子效果受玩家视角影响
