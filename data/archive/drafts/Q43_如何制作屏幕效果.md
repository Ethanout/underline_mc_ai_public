# 如何制作屏幕效果

## 一、概述

在 Minecraft Java Edition 原版数据包中，"屏幕效果"指的是在玩家屏幕上叠加视觉元素，如闪烁、色调变化、画面扭曲等。原版没有直接的"屏幕特效"API，但可以通过多种机制间接实现：

1. **Title/Subtitle/Actionbar** — 文字叠加
2. **Bossbar** — 进度条叠加
3. **粒子效果** — 在玩家视野内生成粒子
4. **药水效果着色** — 利用状态效果的屏幕着色
5. **Fog 控制** — 通过维度/生物群系/状态效果控制雾
6. **资源包配合** — 自定义着色器（shader）实现复杂效果

本文重点介绍前四种纯数据包方案，第五、六种需要资源包配合，仅作简要说明。

---

## 二、方案一：Title/Subtitle/Actionbar 文字叠加

### 原理

Minecraft 的 `title` 命令可以在玩家屏幕中央显示大标题（Title）、小标题（Subtitle）或底部操作栏（Actionbar）。通过设置 `times` 参数控制淡入、停留、淡出时间，可以实现闪烁、滚动等效果。

### 版本要求

- `title` 命令：1.11+
- `title times` 子命令：1.11+
- JSON 文本组件：1.13+

### 完整代码

#### 1. 显示闪烁文字（每 tick 切换显示/隐藏）

`data/<namespace>/function/screen/flash.mcfunction`
```mcfunction
# 每 tick 调用一次，实现闪烁效果
# 使用 scoreboard 控制闪烁状态
scoreboard players add @s flash_tick <namespace>.screen 1
scoreboard players set @s flash_visible <namespace>.screen 0

# 每 10 tick 切换一次可见性（5 tick 显示，5 tick 隐藏）
execute if score @s flash_tick <namespace>.screen matches 0..4 run scoreboard players set @s flash_visible <namespace>.screen 1
execute if score @s flash_tick <namespace>.screen matches 5..9 run scoreboard players set @s flash_visible <namespace>.screen 0
execute if score @s flash_tick <namespace>.screen matches 10 run scoreboard players set @s flash_tick <namespace>.screen 0

# 根据可见性显示或清除标题
execute if score @s flash_visible <namespace>.screen matches 1 run title @s title {"text":"⚠ 警告 ⚠","color":"red","bold":true}
execute if score @s flash_visible <namespace>.screen matches 0 run title @s clear
```

#### 2. 滚动文字效果（利用 times 参数）

`data/<namespace>/function/screen/scroll.mcfunction`
```mcfunction
# 每 20 tick 调用一次，实现文字滚动
# 使用 scoreboard 控制滚动位置
scoreboard players add @s scroll_pos <namespace>.screen 1
execute if score @s scroll_pos <namespace>.screen matches 1 run title @s title {"text":"▶ 系统启动中...","color":"green"}
execute if score @s scroll_pos <namespace>.screen matches 2 run title @s title {"text":"▶ 系统启动中..","color":"green"}
execute if score @s scroll_pos <namespace>.screen matches 3 run title @s title {"text":"▶ 系统启动中.","color":"green"}
execute if score @s scroll_pos <namespace>.screen matches 4 run title @s title {"text":"▶ 系统启动中","color":"green"}
execute if score @s scroll_pos <namespace>.screen matches 5 run scoreboard players set @s scroll_pos <namespace>.screen 1

# 设置淡入/停留/淡出时间（单位：tick）
title @s times 2 15 3
```

### 陷阱与注意事项

1. **标题覆盖**：`title @s title` 会覆盖之前的标题，多个数据包同时使用标题会冲突。建议使用 `actionbar` 作为替代，它不会与标题冲突。
2. **性能**：每 tick 调用 `title` 命令开销较低，但频繁的 JSON 文本解析可能增加延迟。建议使用 `tellraw` 替代高频标题更新。
3. **多玩家**：必须使用 `@s` 选择器，不能使用 `@a` 直接对所有玩家发送不同内容。
4. **JSON 文本限制**：标题不支持 `hoverEvent` 和 `clickEvent`，但支持 `color`、`bold`、`italic` 等样式。

## 三、方案二：Bossbar 进度条效果

### 原理

Bossbar 可以显示在玩家屏幕顶部，支持自定义名称、颜色、分段样式和进度值。通过动态调整进度值，可以实现进度条动画、闪烁、颜色渐变等效果。

### 版本要求

- `bossbar` 命令：1.11+
- Bossbar 颜色/分段：1.11+
- JSON 文本名称：1.13+

### 完整代码

#### 1. 创建并初始化 Bossbar

`data/<namespace>/function/screen/bossbar/load.mcfunction`
```mcfunction
# 创建 bossbar（仅在第一次加载时执行）
bossbar add <namespace>:screen_effect {"text":"","color":"white"}
bossbar set <namespace>:screen_effect max 100
bossbar set <namespace>:screen_effect value 0
bossbar set <namespace>:screen_effect visible false
```

#### 2. 显示进度条动画（从 0 到 100 再回到 0）

`data/<namespace>/function/screen/bossbar/tick.mcfunction`
```mcfunction
# 每 tick 调用一次
# 使用 scoreboard 控制进度
scoreboard players add @s bossbar_progress <namespace>.screen 1

# 当进度达到 100 时反转方向
execute if score @s bossbar_progress <namespace>.screen matches 100 run scoreboard players set @s bossbar_direction <namespace>.screen -1
execute if score @s bossbar_progress <namespace>.screen matches 0 run scoreboard players set @s bossbar_direction <namespace>.screen 1

# 更新进度
scoreboard players operation @s bossbar_progress <namespace>.screen += @s bossbar_direction <namespace>.screen

# 设置 bossbar 进度
execute store result bossbar <namespace>:screen_effect value run scoreboard players get @s bossbar_progress <namespace>.screen

# 显示 bossbar 给玩家
bossbar set <namespace>:screen_effect players @s
bossbar set <namespace>:screen_effect visible true
```

#### 3. 颜色渐变效果

`data/<namespace>/function/screen/bossbar/color.mcfunction`
```mcfunction
# 根据进度值改变颜色
execute if score @s bossbar_progress <namespace>.screen matches 0..25 run bossbar set <namespace>:screen_effect color red
execute if score @s bossbar_progress <namespace>.screen matches 26..50 run bossbar set <namespace>:screen_effect color yellow
execute if score @s bossbar_progress <namespace>.screen matches 51..75 run bossbar set <namespace>:screen_effect color green
execute if score @s bossbar_progress <namespace>.screen matches 76..100 run bossbar set <namespace>:screen_effect color blue
```

### 陷阱与注意事项

1. **Bossbar 数量限制**：每个世界最多 64 个 bossbar，超过会报错。建议复用同一个 bossbar。
2. **可见性**：`bossbar set <id> visible false` 会隐藏所有玩家的 bossbar，但 `bossbar set <id> players @s` 后仍需单独设置可见性。
3. **进度值范围**：`max` 和 `value` 必须是整数，范围 0~2147483647。
4. **多玩家冲突**：如果多个玩家需要不同的进度值，必须为每个玩家创建独立的 bossbar（不推荐），或者使用 `scoreboard` 存储每个玩家的进度，然后统一更新一个 bossbar（但所有玩家看到相同进度）。
5. **性能**：每 tick 更新 bossbar 开销较低，但频繁的 `bossbar set` 命令可能增加网络流量。

## 四、方案三：粒子效果屏幕覆盖

### 原理

在玩家视野内生成大量粒子，可以模拟屏幕效果。通过 `particle` 命令在玩家面前生成粒子，利用粒子的颜色、大小、运动轨迹等属性实现各种视觉效果。

### 版本要求

- `particle` 命令：1.8+
- 粒子参数（如 `dust` 颜色）：1.13+
- 粒子类型 `minecraft:dust`：1.16+
- 粒子类型 `minecraft:block`：1.13+

### 完整代码

#### 1. 屏幕闪烁（白色粒子覆盖）

`data/<namespace>/function/screen/particle/flash.mcfunction`
```mcfunction
# 每 tick 调用一次，在玩家面前生成大量白色粒子
# 使用 scoreboard 控制闪烁状态
scoreboard players add @s flash_tick <namespace>.screen 1

# 每 10 tick 闪烁一次
execute if score @s flash_tick <namespace>.screen matches 0 run particle minecraft:dust 1 1 1 1 ^0 ^0 ^5 2 0 100
execute if score @s flash_tick <namespace>.screen matches 5 run particle minecraft:dust 1 1 1 1 ^0 ^0 ^5 2 0 100
execute if score @s flash_tick <namespace>.screen matches 10 run scoreboard players set @s flash_tick <namespace>.screen 0
```

#### 2. 屏幕边缘模糊效果（环形粒子）

`data/<namespace>/function/screen/particle/edge_blur.mcfunction`
```mcfunction
# 每 tick 调用一次，在玩家视野边缘生成粒子
# 使用 ^ 局部坐标，在玩家前方 3 格处生成环形粒子
particle minecraft:dust 0.5 0.5 0.5 0.5 ^0 ^0 ^3 1.5 0 50
particle minecraft:dust 0.5 0.5 0.5 0.5 ^0 ^0 ^3 1.5 0 50
particle minecraft:dust 0.5 0.5 0.5 0.5 ^0 ^0 ^3 1.5 0 50
```

#### 3. 屏幕震动效果（粒子偏移）

`data/<namespace>/function/screen/particle/shake.mcfunction`
```mcfunction
# 每 tick 调用一次，粒子位置随机偏移
# 使用 scoreboard 生成随机偏移
scoreboard players random @s shake_x <namespace>.screen -5 5
scoreboard players random @s shake_y <namespace>.screen -5 5

# 将随机值转换为浮点数（除以 10）
execute store result score @s shake_x_f <namespace>.screen run scoreboard players get @s shake_x <namespace>.screen
execute store result score @s shake_y_f <namespace>.screen run scoreboard players get @s shake_y <namespace>.screen

# ⚠️ 需验证：scoreboard 无法直接存储浮点数，需要转换为整数后除以 10
# 这里使用简单的整数偏移
particle minecraft:dust 1 0 0 1 ^$(shake_x) ^$(shake_y) ^3 0.5 0 20
```

### 陷阱与注意事项

1. **粒子数量限制**：`particle` 命令的 count 参数不能超过 16384（1.20.5+ 限制为 65536），大量粒子会严重影响性能。
2. **粒子可见性**：粒子只在玩家视野内可见，且受 `particle` 设置影响（`/particle` 命令默认只对执行者可见，除非使用 `@a` 选择器）。
3. **局部坐标**：`^` 局部坐标以玩家朝向为基准，`^x ^y ^z` 分别对应左右、上下、前后。注意 `^0 ^0 ^5` 表示玩家前方 5 格。
4. **粒子类型**：`minecraft:dust` 需要 4 个参数（红、绿、蓝、大小），`minecraft:block` 需要方块 ID。
5. **性能**：每 tick 生成 100 个以上粒子会显著降低帧率，建议控制在 50 个以内。

## 五、方案四：药水效果屏幕着色

### 原理

某些状态效果（如 `minecraft:darkness`、`minecraft:blindness`、`minecraft:nausea`）会改变屏幕显示效果。通过 `effect` 命令给玩家施加这些效果，可以实现屏幕变暗、模糊、扭曲等效果。

### 版本要求

- `effect` 命令：1.8+
- `minecraft:darkness`：1.19+
- `minecraft:nausea`：1.8+
- `minecraft:blindness`：1.8+

### 完整代码

#### 1. 屏幕变暗（黑暗效果）

`data/<namespace>/function/screen/effect/darkness.mcfunction`
```mcfunction
# 给玩家施加黑暗效果，持续 100 tick（5 秒）
effect give @s minecraft:darkness 5 0 true

# 参数说明：
# - 持续时间：5 秒（100 tick）
# - 放大器：0（基础强度）
# - 粒子：true（显示粒子效果，false 则隐藏）
```

#### 2. 屏幕模糊（失明效果）

`data/<namespace>/function/screen/effect/blindness.mcfunction`
```mcfunction
# 给玩家施加失明效果，持续 200 tick（10 秒）
effect give @s minecraft:blindness 10 0 true
```

#### 3. 屏幕扭曲（反胃效果）

`data/<namespace>/function/screen/effect/nausea.mcfunction`
```mcfunction
# 给玩家施加反胃效果，持续 100 tick（5 秒）
effect give @s minecraft:nausea 5 0 true
```

#### 4. 组合效果（黑暗 + 扭曲）

`data/<namespace>/function/screen/effect/combined.mcfunction`
```mcfunction
# 同时施加黑暗和反胃效果
effect give @s minecraft:darkness 5 0 true
effect give @s minecraft:nausea 5 0 true
```

### 陷阱与注意事项

1. **效果叠加**：同一种效果不能叠加，但不同效果可以同时存在。如果已经有效果，再次施加会重置持续时间。
2. **粒子显示**：`true` 参数控制是否显示粒子效果（屏幕角落的药水图标），建议设置为 `true` 以提供视觉反馈。
3. **效果移除**：使用 `effect clear @s minecraft:darkness` 移除特定效果，或 `effect clear @s` 移除所有效果。
4. **版本差异**：`minecraft:darkness` 在 1.19 之前不存在，低版本请使用 `minecraft:blindness` 替代。
5. **性能**：效果本身开销极低，但频繁的 `effect give` 命令（每 tick）会增加命令执行次数。

## 六、方案对比

| 方案 | 版本要求 | 性能开销 | 视觉效果 | 适用场景 |
|------|---------|---------|---------|---------|
| Title/Actionbar | 1.11+ | 低 | 文字叠加 | 提示信息、闪烁警告 |
| Bossbar | 1.11+ | 低 | 进度条 | 加载进度、计时器 |
| 粒子效果 | 1.8+ | 中-高 | 粒子覆盖 | 闪烁、模糊、震动 |
| 药水效果 | 1.8+ | 极低 | 屏幕着色 | 黑暗、模糊、扭曲 |
| 资源包着色器 | 1.16+ | 中 | 自定义着色 | 复杂屏幕效果 |

### 推荐组合

- **简单提示**：Title/Actionbar + Bossbar
- **沉浸式效果**：药水效果 + 粒子效果
- **高性能需求**：药水效果（开销最低）
- **复杂视觉效果**：资源包着色器（需要额外资源包）

## 七、陷阱与注意事项（通用）

1. **命令执行频率**：每 tick 执行 `title`、`bossbar`、`particle` 命令会增加服务器负载。建议使用 `schedule` 或 `scoreboard` 控制执行频率。
2. **多玩家同步**：所有方案都需要为每个玩家单独执行命令，不能使用 `@a` 直接广播。
3. **资源包依赖**：如果使用自定义着色器，玩家必须安装资源包，否则看不到效果。
4. **版本兼容性**：不同版本间命令语法和粒子类型可能有差异，建议在目标版本测试。
5. **调试**：使用 `gamerule commandBlockOutput false` 减少命令输出，使用 `gamerule logAdminCommands false` 隐藏日志。
