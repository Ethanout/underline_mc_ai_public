# 如何让敌人攻击玩家

## 核心挑战

在 Minecraft 原版数据包中，没有直接的“实体 A 攻击实体 B”命令。`/damage` 命令（1.19.4+）可以造成伤害，但无法触发原版攻击机制中的击退、附魔效果（如火焰附加）、攻击冷却、战利品表掉落等。因此，实现“敌人攻击玩家”需要模拟或触发原版攻击系统的不同部分。

## 方案一：使用 `/damage` 命令（最直接，1.19.4+）

### 原理

利用 `/damage` 命令直接对目标实体造成伤害。这是最简洁的方式，但无法触发攻击者的攻击冷却、附魔效果、以及基于攻击者的战利品表（如玩家击杀掉落）。

### 完整代码

**文件路径：** `data/<namespace>/function/enemy/attack_player.mcfunction`

```mcfunction
# 假设 @s 是敌人，@p 是最近的玩家
# 造成 5 点伤害（2.5 颗心），伤害类型为 mob_attack
execute as @e[type=zombie,tag=enemy] at @s run damage @p 5 minecraft:mob_attack
```

**进阶：使用自定义伤害类型（1.19.4+）**

创建自定义伤害类型可以控制击退、伤害类型标签等。

**文件路径：** `data/<namespace>/damage_type/enemy_attack.json`

```json
{
  "exhaustion": 0.1,
  "message_id": "enemy_attack",
  "scaling": "when_caused_by_living_non_player",
  "effects": "hurt",
  "death_message_type": "default"
}
```

然后在命令中引用：

```mcfunction
damage @p 5 <namespace>:enemy_attack
```

### 陷阱与注意事项

1. **无法触发攻击者附魔**：`/damage` 造成的伤害不携带攻击者的武器附魔效果（如火焰附加、击退）。如需模拟，需手动添加效果。
2. **无攻击冷却**：敌人可以每 tick 攻击一次，需自行控制攻击频率（如使用 scoreboard 计时）。
3. **无战利品表触发**：如果玩家被“敌人”杀死，掉落物由玩家死亡机制决定，而非敌人的战利品表。如需自定义掉落，需监听玩家死亡事件。
4. **伤害类型选择**：使用 `minecraft:mob_attack` 会触发生物攻击音效和击退，但击退方向固定为攻击者朝向。如需自定义击退，需使用 `minecraft:player_attack` 或自定义伤害类型并设置 `knockback` 字段（⚠️ 需验证：自定义伤害类型是否支持 `knockback` 字段，1.21+ 的伤害类型 JSON 格式中 `knockback` 是可选字段）。

## 方案二：模拟攻击（1.20.5+，利用物品组件）

### 原理

通过 `item` 命令给敌人装备武器，然后利用 `execute on` 或 `ride` 机制让敌人“使用”武器攻击。但原版没有“强制攻击”命令，因此需要结合 `/damage` 和手动附加效果。

更高级的模拟：让敌人手持武器，然后通过 `/damage` 造成伤害，再手动应用武器附魔效果。

### 完整代码

**文件路径：** `data/<namespace>/function/enemy/attack_with_weapon.mcfunction`

```mcfunction
# 假设 @s 是敌人，手持钻石剑（附魔火焰附加 II）
# 1. 造成基础伤害（钻石剑基础伤害 7）
damage @p 7 minecraft:player_attack

# 2. 手动应用火焰附加效果（4 秒火焰）
effect give @p minecraft:fire_resistance 0 0 true  # 错误示范，应为火焰伤害
# 正确：应用火焰附加效果
execute if predicate <namespace>:has_fire_aspect run effect give @p minecraft:fire 4 0 true
```

**谓词：检测敌人主手是否有火焰附加**

**文件路径：** `data/<namespace>/predicate/has_fire_aspect.json`

```json
{
  "condition": "minecraft:entity_properties",
  "entity": "this",
  "predicate": {
    "equipment": {
      "mainhand": {
        "enchantments": [
          {
            "enchantment": "minecraft:fire_aspect",
            "levels": {
              "min": 1
            }
          }
        ]
      }
    }
  }
}
```

### 陷阱与注意事项

1. **手动模拟不完整**：击退、横扫之刃等效果需要手动实现，代码量较大。
2. **伤害类型选择**：使用 `player_attack` 会触发玩家攻击音效和击退，但击退方向为攻击者朝向。使用 `mob_attack` 则更自然。
3. **武器耐久度**：`/damage` 不会消耗武器耐久，需手动减少（使用 `item damage` 命令，1.20.5+）。

## 方案三：利用 `hurt_entity` 进度触发（1.16+）

### 原理

创建一个进度，当玩家伤害实体时触发，然后通过函数反向“模拟”敌人攻击。但这实际上是玩家攻击敌人，而非敌人攻击玩家。常用于实现“反击”或“受伤反馈”机制。

### 完整代码

**文件路径：** `data/<namespace>/advancement/enemy_hurt_player.json`

```json
{
  "criteria": {
    "hurt_by_enemy": {
      "trigger": "minecraft:entity_hurt_player",
      "conditions": {
        "damage": {
          "type": {
            "source_entity": {
              "type": "minecraft:zombie"
            }
          }
        }
      }
    }
  },
  "rewards": {
    "function": "<namespace>:on_hurt_by_enemy"
  }
}
```

**文件路径：** `data/<namespace>/function/on_hurt_by_enemy.mcfunction`

```mcfunction
# 当玩家被僵尸伤害时触发
# 可以在这里执行反击逻辑，但无法改变伤害本身
say 我被僵尸攻击了！
```

### 陷阱与注意事项

1. **无法改变伤害**：进度触发在伤害发生后，无法用于修改伤害值或取消伤害。
2. **仅用于反馈**：适合实现受伤后的效果（如屏幕震动、粒子效果），而非控制攻击行为。
3. **性能开销**：每个玩家每次受伤都会触发进度，高频伤害场景下需注意性能。

## 方案四：使用 `@e` 选择器 + 碰撞箱检测（1.13+）

### 原理

通过检测敌人与玩家的碰撞箱重叠，模拟近战攻击。这种方法不依赖原版攻击系统，完全由数据包控制。

### 完整代码

**文件路径：** `data/<namespace>/function/enemy/melee_check.mcfunction`

```mcfunction
# 每 tick 执行，检测所有 tagged 敌人
execute as @e[type=zombie,tag=enemy] at @s run function <namespace>:enemy/melee_attack
```

**文件路径：** `data/<namespace>/function/enemy/melee_attack.mcfunction`

```mcfunction
# 检测攻击范围内是否有玩家
execute positioned ^ ^ ^1 if entity @p[distance=..1.5] run function <namespace>:enemy/attack_player
```

**文件路径：** `data/<namespace>/function/enemy/attack_player.mcfunction`

```mcfunction
# 攻击冷却控制（使用 scoreboard）
scoreboard players add @s attack_cooldown 1
execute if score @s attack_cooldown matches 20.. run function <namespace>:enemy/do_attack
```

**文件路径：** `data/<namespace>/function/enemy/do_attack.mcfunction`

```mcfunction
# 重置冷却
scoreboard players set @s attack_cooldown 0

# 造成伤害
damage @p[distance=..1.5] 5 minecraft:mob_attack

# 击退效果（手动实现）
execute at @s facing entity @p feet run tp @p ^ ^ ^0.5
```

### 陷阱与注意事项

1. **碰撞箱精度**：`^ ^ ^1` 表示敌人前方 1 格，但实际攻击范围需根据实体类型调整（僵尸为 1.5 格）。
2. **多玩家处理**：`@p` 可能不是目标玩家，需使用更精确的选择器（如 `@a[sort=nearest,limit=1]`）。
3. **性能开销**：每 tick 对所有敌人执行检测，大量敌人时性能下降。建议使用 `distance` 预过滤。
4. **击退实现粗糙**：`tp` 命令实现的击退不自然，且可能将玩家推入方块。建议使用 `velocity` 命令（1.20.5+）或 `motion` NBT 修改。

## 方案对比

## 推荐方案

### 简单场景（1.19.4+）：使用 `/damage` 命令

```mcfunction
# 每 20 tick 执行一次（每秒）
execute as @e[type=zombie,tag=enemy] at @s if entity @p[distance=..2] run damage @p 5 minecraft:mob_attack
```

### 复杂场景（1.20.5+）：模拟攻击 + 物品组件

需要创建攻击冷却系统、附魔效果系统、击退系统。以下是一个完整示例框架：

**文件路径：** `data/<namespace>/function/enemy/tick.mcfunction`

```mcfunction
# 主循环
execute as @e[type=zombie,tag=enemy] at @s run function <namespace>:enemy/attack_cycle
```

**文件路径：** `data/<namespace>/function/enemy/attack_cycle.mcfunction`

```mcfunction
# 冷却控制
scoreboard players add @s attack_cooldown 1
execute if score @s attack_cooldown matches 10.. run function <namespace>:enemy/try_attack
```

**文件路径：** `data/<namespace>/function/enemy/try_attack.mcfunction`

```mcfunction
# 检测目标
execute if entity @p[distance=..2] run function <namespace>:enemy/perform_attack
```

**文件路径：** `data/<namespace>/function/enemy/perform_attack.mcfunction`

```mcfunction
# 重置冷却
scoreboard players set @s attack_cooldown 0

# 获取武器伤害（简化：固定值）
damage @p[distance=..2] 7 minecraft:player_attack

# 应用火焰附加
execute if predicate <namespace>:has_fire_aspect run effect give @p[distance=..2] minecraft:fire 4 0 true

# 应用击退（使用 velocity）
execute at @s facing entity @p[distance=..2] feet positioned ^ ^ ^1 run velocity @p[distance=..2] add 0 0.5 0
```

## 陷阱总结

1. **版本兼容性**：`/damage` 命令在 1.19.4 之前不可用，需使用 `effect` 或 `data` 修改生命值（不推荐）。
2. **攻击频率控制**：必须使用 scoreboard 控制，否则敌人会每 tick 攻击。
3. **多玩家环境**：`@p` 选择器可能不准确，建议使用 `@a[sort=nearest,limit=1]` 并配合距离检测。
4. **击退方向**：`/damage` 的击退方向基于攻击者朝向，如需自定义方向需手动实现。
5. **伤害类型标签**：使用 `minecraft:player_attack` 会触发玩家攻击音效，使用 `minecraft:mob_attack` 更自然但击退较弱。
