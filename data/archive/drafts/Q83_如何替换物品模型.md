# 如何选取自定义物品模板与替换模型

数据包无法真正注册新物品，因此制作自定义物品（如武器、技能书、UI图标）时，必须选择一个原版物品作为“模板”（Base Item）。

## 一、 模板物品选取原则

理想的模板物品应具备**零交互性**，避免原版行为干扰游戏体验。交互包括：
1.  **方块交互**：右键点击方块时产生效果（如书放入雕文书架、方块放置、锄地）。
2.  **合成参与**：物品是某个原版高级物品的合成材料（防止玩家误合成丢掉道具）。
3.  **生物交互**：引起生物特定行为（如胡萝卜钓竿吸引猪、骨头吸引狼）。
4.  **数据纯净**：物品本身不带有复杂的 NBT 或组件逻辑，方便完全自定义。

## 二、 推荐模板物品

### 1. 追溯指针 (Recovery Compass) —— 【最推荐】
自 1.19 加入以来，它是最理想的模板物品：
-   **无交互**：右键点击任何方块或生物均无反应。
-   **无合成**：不参与任何原版合成配方。
-   **无数据**：不像普通指南针需要指向坐标，它在不处理死亡点时非常纯净。
-   **全版本适用**：1.19.4+ 均可放心使用。

### 2. 禁用了播放组件的唱片 (Music Discs)
在 1.21.5+ 中，可以利用组件禁用唱片机的交互：
-   使用 `!jukebox_playable` 组件。
-   这样唱片就变成了纯粹的占位物品，无法放入唱片机。

### 3. 烟火之星 (Firework Star)
虽然在社区中常见，但其由于历史遗留问题，在某些版本或特定操作下可能仍带有烟花属性，且其外观包含颜色数据，不如追溯指针纯粹。

## 三、 替换模型方法

### 1. 资源包配置
在资源包中，利用 `overrides` 或 1.21.4+ 的 `item_model` 逻辑。

**1.21.4+ 推荐做法：**
在 `assets/minecraft/items/recovery_compass.json` 中配置：
```json
{
  "model": {
    "type": "minecraft:select",
    "property": "minecraft:custom_model_data",
    "cases": [
      { "when": 1, "model": { "type": "minecraft:model", "model": "mynamespace:item/cool_sword" } },
      { "when": 2, "model": { "type": "minecraft:model", "model": "mynamespace:item/magic_wand" } }
    ],
    "fallback": { "type": "minecraft:model", "model": "minecraft:item/recovery_compass" }
  }
}
```

### 2. 给予物品命令
```mcfunction
# 给予自定义模型物品
give @s recovery_compass[custom_model_data=1,custom_name='{"text":"神剑","italic":false}']
```

## 四、 常见坑点
-   **胡萝卜钓竿**：仅用于需要检测右键的场景。如果只需外观或非右键交互，**绝不**推荐使用，因为它会吸引猪。
-   **管理员物品**：如屏障、结构方块，其实都带有一定的交互或放置逻辑，不适合作为通用模板。
