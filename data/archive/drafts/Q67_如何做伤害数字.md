# 如何做伤害数字

## 核心挑战

Minecraft 原版没有内置的"伤害数字"显示机制（不同于 Java Edition 的伤害指示器或 Bedrock Edition 的伤害数字）。数据包开发者需要利用现有的显示机制来模拟伤害数字效果，主要面临以下挑战：

1. **实时性**：伤害数字需要在受到伤害的瞬间出现
2. **位置跟随**：数字需要出现在受击实体附近
3. **动画效果**：数字需要向上飘动并消失
4. **性能开销**：高频伤害场景（如快速连击）不能产生大量实体

## 方案一：利用 `area_effect_cloud` + `CustomName` 显示伤害数字

**适用版本**：1.13+
**推荐程度**：⭐⭐⭐⭐（最通用、最稳定）

### 原理

1. 通过 `damage` 进度监听玩家造成伤害
2. 在受击实体位置生成 `area_effect_cloud`（AEC），设置其 `CustomName` 为伤害数值
3. AEC 自动向上飘动（利用 `Motion` 标签）并在指定时间后消失（利用 `Age` 标签）
4. 通过 `CustomNameVisible` 使名称始终可见

### 完整实现

#### 1. 监听伤害的进度

`data/<namespace>/advancement/damage/detect.json`
```json
{
  "criteria": {
    "deal_damage": {
      "trigger": "minecraft:player_hurt_entity",
      "conditions": {
        "damage": {
          "dealt": {
            "min": 0
          }
        }
      }
    }
  },
  "rewards": {
    "function": "<namespace>:damage/show_number"
  }
}
```

#### 2. 显示伤害数字的函数

`data/<namespace>/function/damage/show_number.mcfunction`
```mcfunction
# 存储伤害值到 scoreboard
scoreboard players set @s damage_dealt 0
execute store result score @s damage_dealt run data get entity @s LastDamage 1

# 在受击实体位置生成 AEC
execute at @e[type=#<namespace>:damage_targets,sort=nearest,limit=1] run summon minecraft:area_effect_cloud ~ ~1 ~ {Duration:20,Age:0,Motion:[0.0,0.3,0.0],CustomNameVisible:1b,NoGravity:1b,Invulnerable:1b,Tags:["damage_number"]}

# 设置伤害数字的 CustomName
execute as @e[type=minecraft:area_effect_cloud,tag=damage_number,sort=nearest,limit=1] run function <namespace>:damage/set_name

# 撤销进度，准备下一次触发
advancement revoke @s only <namespace>:damage/detect
```

#### 3. 设置名称的函数

`data/<namespace>/function/damage/set_name.mcfunction`
```mcfunction
# 从 scoreboard 读取伤害值并设置名称
scoreboard players operation @s damage_dealt = @p damage_dealt
execute store result storage <namespace>:damage temp int 1 run scoreboard players get @s damage_dealt
data modify entity @s CustomName set value '{"text":"<伤害值>","color":"red","bold":true}'
```

**⚠️ 需验证**：`data get entity @s LastDamage` 在 1.20.5+ 中是否仍然可用。在 1.20.5 中，实体伤害存储方式有变化，可能需要使用 `data get entity @s HurtEntities` 或 `data get entity @s RecentDamageSource`。

### 陷阱与注意事项

1. **实体类型标签**：`#<namespace>:damage_targets` 需要预先定义，包含所有可能被伤害的实体类型（玩家、生物、盔甲架等）
2. **多目标问题**：当玩家同时伤害多个实体时（如范围伤害），`@e[sort=nearest,limit=1]` 可能选错目标。建议使用 `@e[type=...]` 配合距离排序
3. **AEC 堆积**：高频伤害会产生大量 AEC，建议设置合理的 `Duration`（如 20 ticks = 1秒）并定期清理
4. **名称显示**：`CustomNameVisible:1b` 使名称始终可见，但 AEC 本身不可见，只有名称会显示
5. **飘动效果**：`Motion:[0.0,0.3,0.0]` 使 AEC 向上飘动，但实际效果受服务器 tick 影响，可能不够平滑

## 方案二：利用 `text_display` 实体显示伤害数字

**适用版本**：1.19.4+
**推荐程度**：⭐⭐⭐⭐⭐（视觉效果最佳）

### 原理

1. 使用 1.19.4 引入的 `text_display` 实体
2. 设置 `text` 为伤害数值，`billboard` 为 `center`（始终面向玩家）
3. 通过 `teleport` 或 `Motion` 实现飘动动画
4. 利用 `start_interpolation` 和 `interpolation_duration` 实现平滑动画

### 完整实现

#### 1. 监听伤害的进度（同方案一）

`data/<namespace>/advancement/damage/detect.json`
```json
{
  "criteria": {
    "deal_damage": {
      "trigger": "minecraft:player_hurt_entity",
      "conditions": {
        "damage": {
          "dealt": {
            "min": 0
          }
        }
      }
    }
  },
  "rewards": {
    "function": "<namespace>:damage/show_number_v2"
  }
}
```

#### 2. 显示伤害数字的函数

`data/<namespace>/function/damage/show_number_v2.mcfunction`
```mcfunction
# 存储伤害值
scoreboard players set @s damage_dealt 0
execute store result score @s damage_dealt run data get entity @s LastDamage 1

# 在受击实体位置生成 text_display
execute at @e[type=#<namespace>:damage_targets,sort=nearest,limit=1] run summon minecraft:text_display ~ ~1 ~ {billboard:"center",see_through:1b,shadow:1b,background:0,text:'{"text":"0","color":"red","bold":true}',transformation:[1f,0f,0f,0f,0f,1f,0f,0f,0f,0f,1f,0f,0f,0f,0f,1f],start_interpolation:0,interpolation_duration:20,Tags:["damage_number_v2"]}

# 设置伤害数值
execute as @e[type=minecraft:text_display,tag=damage_number_v2,sort=nearest,limit=1] run function <namespace>:damage/set_name_v2

# 撤销进度
advancement revoke @s only <namespace>:damage/detect
```

#### 3. 设置名称的函数

`data/<namespace>/function/damage/set_name_v2.mcfunction`
```mcfunction
# 从 scoreboard 读取伤害值
scoreboard players operation @s damage_dealt = @p damage_dealt
execute store result storage <namespace>:damage temp int 1 run scoreboard players get @s damage_dealt

# 设置 text_display 的文本
data modify entity @s text set value '{"text":"<伤害值>","color":"red","bold":true}'

# 启动飘动动画（使用 interpolation）
data modify entity @s teleport_interpolation_duration set value 20
data modify entity @s pos set from entity @s Pos
# 设置目标位置（向上飘动 2 格）
execute store result entity @s pos[1] double 0.05 run data get entity @s Pos[1]
```

**⚠️ 需验证**：`teleport_interpolation_duration` 和 `pos` 的修改方式是否正确。在 1.19.4+ 中，`text_display` 的插值系统可能使用不同的 NBT 路径。

### 陷阱与注意事项

1. **版本要求**：`text_display` 仅在 1.19.4+ 可用
2. **性能开销**：`text_display` 比 AEC 更重，高频生成时需要注意性能
3. **插值动画**：`interpolation_duration` 控制动画时长（单位：tick），需要配合 `start_interpolation` 使用
4. **背景透明**：`background:0` 使背景完全透明，否则会显示白色背景
5. **始终可见**：`see_through:1b` 使文字穿过方块可见，但可能影响视觉效果

## 方案三：利用 `item_display` 显示伤害数字（图片方式）

**适用版本**：1.19.4+
**推荐程度**：⭐⭐⭐（适合需要自定义字体样式的场景）

### 原理

1. 预先制作包含数字的纹理图片（如 0-9 的数字精灵图）
2. 使用 `item_display` 实体显示带有自定义模型的物品
3. 根据伤害值选择对应的模型变体
4. 通过 `transformation` 控制显示位置和大小

### 完整实现（简化版）

#### 1. 资源包准备

需要准备一个资源包，包含：
- 数字纹理（如 `assets/<namespace>/textures/damage/numbers.png`）
- 模型文件（如 `assets/<namespace>/models/item/damage_number.json`）

#### 2. 生成显示实体

`data/<namespace>/function/damage/show_number_v3.mcfunction`
```mcfunction
# 存储伤害值
scoreboard players set @s damage_dealt 0
execute store result score @s damage_dealt run data get entity @s LastDamage 1

# 生成 item_display
execute at @e[type=#<namespace>:damage_targets,sort=nearest,limit=1] run summon minecraft:item_display ~ ~1 ~ {item:{id:"minecraft:paper",components:{"minecraft:custom_model_data":1}},transformation:[0.5f,0f,0f,0f,0f,0.5f,0f,0f,0f,0f,0.5f,0f,0f,0f,0f,1f],Tags:["damage_number_v3"]}

# 根据伤害值设置模型变体
execute as @e[type=minecraft:item_display,tag=damage_number_v3,sort=nearest,limit=1] run function <namespace>:damage/set_model

# 撤销进度
advancement revoke @s only <namespace>:damage/detect
```

### 陷阱与注意事项

1. **资源包依赖**：需要玩家安装资源包才能看到自定义纹理
2. **多位数处理**：需要为每个数字位单独生成实体，或使用复杂的模型变体
3. **性能开销**：`item_display` 的渲染开销较高
4. **维护成本**：需要维护资源包和数据包的同步

## 方案对比

| 方案 | 版本要求 | 视觉效果 | 性能开销 | 资源包依赖 | 实现复杂度 |
|------|----------|----------|----------|------------|------------|
| AEC + CustomName | 1.13+ | 一般（文字可能闪烁） | 低 | 否 | 低 |
| text_display | 1.19.4+ | 优秀（平滑动画） | 中 | 否 | 中 |

## 通用陷阱与最佳实践

### 1. 伤害值获取的版本差异

- **1.20.5 之前**：`data get entity @s LastDamage` 可用
- **1.20.5+**：`LastDamage` 可能被移除，需要使用 `data get entity @s HurtEntities` 或 `data get entity @s RecentDamageSource` ⚠️ 需验证

### 2. 多实体伤害处理

当玩家使用范围伤害（如爆炸、横扫之刃）时，`player_hurt_entity` 进度会多次触发。建议：
- 使用 `@e[sort=nearest,limit=1]` 配合距离排序
- 或使用 `@e[type=...]` 精确指定目标类型

### 3. 实体清理

高频伤害场景（如快速连击）会产生大量显示实体，建议：
- 设置合理的 `Duration`（AEC）或使用定时清理函数
- 使用 `schedule` 在指定时间后清除实体

```mcfunction
# 清理函数（每 5 秒执行一次）
schedule function <namespace>:damage/cleanup 100s

# cleanup.mcfunction
kill @e[type=minecraft:area_effect_cloud,tag=damage_number]
kill @e[type=minecraft:text_display,tag=damage_number_v2]
```

### 4. 玩家自身伤害

当玩家伤害自己时（如反伤、荆棘附魔），`player_hurt_entity` 进度不会触发。需要使用 `entity_hurt_player` 进度来监听玩家受到伤害。

## 推荐方案

对于大多数场景，推荐使用 **方案二（text_display）**，因为：
1. 视觉效果最佳（平滑动画、始终面向玩家）
2. 无需资源包
3. 实现相对简单
4. 1.19.4+ 版本已广泛使用

如果需要在 1.13-1.19.3 版本中使用，则选择 **方案一（AEC + CustomName）**。
