# 如何做射线检测

## 核心挑战

在 Minecraft 原版数据包中实现射线检测（Raycast）面临以下挑战：
1. **无原生 API**：Minecraft 没有提供直接的射线检测命令或函数
2. **精度与性能平衡**：步长越小精度越高，但实体检测次数越多，性能开销越大
3. **版本差异**：不同版本中实体标记、位置获取、方块检测的机制不同
4. **边界情况**：玩家视角方向、实体碰撞箱、方块碰撞箱的处理

## 方案一：逐步推进法（最通用，推荐）

### 原理

从玩家眼睛位置出发，沿视线方向以固定步长逐步前进，每一步检测该位置是否有方块阻挡或实体存在。通过 `execute positioned` 和 `execute if block` 实现方块检测，通过 `@e[distance=..半径]` 实现实体检测。

### 适用版本
1.13+（所有支持数据包的版本）

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    functions/
      raycast/
        main.mcfunction          # 入口函数
        step.mcfunction          # 单步推进逻辑
        hit_block.mcfunction     # 击中方块时的处理
        hit_entity.mcfunction    # 击中实体时的处理
        reset.mcfunction         # 重置射线状态
    tags/
      functions/
        tick.json                # 每 tick 调用
```

#### 1. 初始化（load 函数）
```mcfunction
# data/<namespace>/functions/load.mcfunction
scoreboard objectives add raycast.distance dummy
scoreboard objectives add raycast.max_distance dummy
scoreboard objectives add raycast.step dummy
```

#### 2. 每 tick 调用入口
```json
// data/<namespace>/tags/functions/tick.json
{
  "values": [
    "<namespace>:raycast/main"
  ]
}
```

#### 3. 主函数
```mcfunction
# data/<namespace>/functions/raycast/main.mcfunction
# 为每个玩家执行射线检测
execute as @a at @s anchored eyes run function <namespace>:raycast/step
```

#### 4. 步进函数
```mcfunction
# data/<namespace>/functions/raycast/step.mcfunction
# 参数说明：
#   raycast.distance - 当前已前进的距离（以步数为单位）
#   raycast.max_distance - 最大检测距离（以步数为单位）
#   raycast.step - 步长（以0.1为单位，如10表示1.0格）

# 检查是否超过最大距离
execute if score @s raycast.distance >= @s raycast.max_distance run return run function <namespace>:raycast/reset

# 检查当前位置是否有方块阻挡（非空气方块）
execute unless block ~ ~ ~ air run return run function <namespace>:raycast/hit_block

# 检查当前位置是否有实体（排除自己）
execute if entity @e[type=!minecraft:player,distance=..0.5,limit=1] run return run function <namespace>:raycast/hit_entity

# 沿视线方向前进
execute positioned ^ ^ ^.1 run function <namespace>:raycast/step_inner
```

#### 5. 内部步进函数（处理距离累加）
```mcfunction
# data/<namespace>/functions/raycast/step_inner.mcfunction
scoreboard players add @s raycast.distance 1
execute positioned ^ ^ ^.1 run function <namespace>:raycast/step
```

#### 6. 击中方块处理
```mcfunction
# data/<namespace>/functions/raycast/hit_block.mcfunction
# 在此处编写击中方块后的逻辑
# 例如：放置粒子效果
particle minecraft:flame ~ ~ ~ 0 0 0 0.1 1

# 重置射线状态
function <namespace>:raycast/reset
```

#### 7. 击中实体处理
```mcfunction
# data/<namespace>/functions/raycast/hit_entity.mcfunction
# 在此处编写击中实体后的逻辑
# 例如：对实体造成伤害
execute as @e[type=!minecraft:player,distance=..0.5,limit=1] run damage @s 5 minecraft:player_attack

# 重置射线状态
function <namespace>:raycast/reset
```

#### 8. 重置函数
```mcfunction
# data/<namespace>/functions/raycast/reset.mcfunction
scoreboard players set @s raycast.distance 0
```

### 陷阱与注意事项

1. **步长选择**：步长越小精度越高，但性能开销越大。推荐步长为 0.1 格（即 `^ ^ ^.1`），最大距离 100 格（1000 步）
2. **实体检测半径**：`distance=..0.5` 可能漏检小实体（如蝙蝠），建议根据需求调整
3. **玩家自身排除**：`@e[type=!minecraft:player]` 会排除所有玩家，如果只想排除自己，需要使用 `@s` 标记
4. **方块检测精度**：`unless block ~ ~ ~ air` 只能检测精确坐标的方块，如果射线穿过方块边缘可能漏检
5. **性能问题**：每 tick 为每个玩家执行 1000 步检测，20 个玩家时每 tick 执行 20000 次命令，性能开销较高

## 方案二：实体标记法（1.20.5+，性能最优）

### 原理

利用 1.20.5 引入的 `item_display` 或 `marker` 实体作为"射线探针"。在玩家位置生成一个标记实体，然后通过 `execute on` 或 `execute at` 沿视线方向移动该实体，检测其位置是否有方块或实体。

### 适用版本
1.20.5+

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    functions/
      raycast/
        init.mcfunction          # 初始化射线实体
        move.mcfunction          # 移动射线实体
        check.mcfunction         # 检测碰撞
        cleanup.mcfunction       # 清理射线实体
    tags/
      functions/
        tick.json
```

#### 1. 初始化
```mcfunction
# data/<namespace>/functions/raycast/init.mcfunction
# 为每个玩家生成一个 marker 实体作为射线探针
execute as @a run summon minecraft:marker ~ ~ ~ {Tags:["raycast_probe"]}
```

#### 2. 每 tick 移动和检测
```mcfunction
# data/<namespace>/functions/raycast/move.mcfunction
# 移动所有射线探针
execute as @e[tag=raycast_probe] at @s run function <namespace>:raycast/check
```

#### 3. 检测函数
```mcfunction
# data/<namespace>/functions/raycast/check.mcfunction
# 检查当前位置是否有方块
execute unless block ~ ~ ~ air run function <namespace>:raycast/hit_block

# 检查当前位置是否有实体（排除自己和射线探针）
execute if entity @e[type=!minecraft:player,tag=!raycast_probe,distance=..0.5,limit=1] run function <namespace>:raycast/hit_entity

# 沿视线方向移动
execute positioned ^ ^ ^.1 run tp @s ~ ~ ~
```

#### 4. 清理函数
```mcfunction
# data/<namespace>/functions/raycast/cleanup.mcfunction
# 当玩家退出或射线完成时清理
kill @e[tag=raycast_probe]
```

### 陷阱与注意事项

1. **实体数量**：每个玩家需要一个 marker 实体，大量玩家时实体数量会增多
2. **多世界问题**：如果使用多世界插件，marker 实体可能在不同维度间混乱
3. **玩家退出处理**：玩家退出后 marker 实体需要清理，否则会残留
4. **tp 命令限制**：`tp` 命令在 1.20.5+ 中支持相对坐标，但需要确保方向正确

## 方案三：递归函数法（1.20.2+，代码简洁）

### 原理

利用 1.20.2 引入的 `return run` 功能，通过递归函数实现射线推进。每次调用自身并增加步数，直到达到最大距离或击中目标。

### 适用版本
1.20.2+

### 完整实现

#### 目录结构
```
data/
  <namespace>/
    functions/
      raycast/
        start.mcfunction         # 启动射线
        advance.mcfunction       # 递归推进
        hit.mcfunction           # 击中处理
```

#### 1. 启动函数
```mcfunction
# data/<namespace>/functions/raycast/start.mcfunction
# 设置初始参数
scoreboard players set @s raycast.distance 0
scoreboard players set @s raycast.max_distance 100
execute anchored eyes positioned ^ ^ ^ run function <namespace>:raycast/advance
```

#### 2. 递归推进函数
```mcfunction
# data/<namespace>/functions/raycast/advance.mcfunction
# 检查是否超过最大距离
execute if score @s raycast.distance >= @s raycast.max_distance run return 0

# 检查方块
execute unless block ~ ~ ~ air run return run function <namespace>:raycast/hit

# 检查实体
execute if entity @e[type=!minecraft:player,distance=..0.5,limit=1] run return run function <namespace>:raycast/hit

# 前进并递归
scoreboard players add @s raycast.distance 1
execute positioned ^ ^ ^.1 run return run function <namespace>:raycast/advance
```

#### 3. 击中处理
```mcfunction
# data/<namespace>/functions/raycast/hit.mcfunction
# 击中逻辑
particle minecraft:flame ~ ~ ~ 0 0 0 0.1 1
return 1
```

### 陷阱与注意事项

1. **递归深度限制**：Minecraft 函数递归深度有限制（约 65536 层），但 1000 步的射线检测不会触发此限制
2. **性能开销**：递归函数每层调用都有开销，但比方案一的循环调用略优
3. **版本要求**：必须 1.20.2+，且需要 `return run` 支持

### 推荐场景

- **通用场景**：逐步推进法（方案一），兼容性好，实现简单
- **高性能需求**：实体标记法（方案二），但需要 1.20.5+
- **代码简洁优先**：递归函数法（方案三），但需要 1.20.2+

## 进阶技巧

### 1. 精确的视线方向计算

如果需要更精确的视线方向（如弓箭轨迹），可以使用 `execute rotated` 结合数学计算：

```mcfunction
# 获取玩家视角方向
execute as @a at @s anchored eyes run function <namespace>:raycast/get_direction
```

### 2. 碰撞箱检测

对于方块碰撞箱（如楼梯、栅栏），不能仅检测空气方块，需要使用 `if block` 配合精确的方块状态：

```mcfunction
# 检测非空气且非透明方块
execute unless block ~ ~ ~ #minecraft:air unless block ~ ~ ~ #minecraft:replaceable run function <namespace>:raycast/hit_block
```

### 3. 实体碰撞箱优化

使用 `@e[type=!minecraft:player,distance=..0.5,sort=nearest,limit=1]` 获取最近的实体，避免多次检测。

### 4. 性能优化建议

- 使用 `schedule` 函数降低检测频率（如每 2 tick 检测一次）
- 限制最大检测距离（建议 50-100 格）
- 使用 `tag` 标记已检测的实体，避免重复检测

## 陷阱总结

1. **步长与精度**：步长过大会导致漏检小物体，步长过小会导致性能问题
2. **玩家自身检测**：需要排除玩家自身，否则射线会立即击中自己
3. **多维度问题**：在不同维度中执行射线检测时，需要确保实体在同一维度
4. **方块更新延迟**：方块被破坏后，`if block` 检测可能仍有延迟
5. **实体移动**：在检测过程中实体可能移动，导致检测结果不准确
