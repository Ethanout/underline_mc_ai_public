# 命令方块基础与摆法

## 获取
```mcfunction
give @s command_block          # 橙色（脉冲）
give @s chain_command_block    # 绿色（连锁）
give @s repeating_command_block # 紫色（循环）
```
也可在辅助功能 → 管理员用品标签页直接拿取。

## 三种类型
| 类型 | 颜色 | 行为 |
|------|------|------|
| 脉冲（Command Block） | 橙色 | 被激活时执行一次 |
| 连锁（Chain Command Block） | 绿色 | 上一个执行后触发 |
| 循环（Repeating Command Block） | 紫色 | 每 tick 执行一次 |

## 命令链标准摆放
```
抬头摆放，节约平面空间：

1. 放紫色循环方块（红石控制）
2. 对着圆形面，按住 Shift 向上叠放绿色连锁方块
3. 所有绿色方块设为"保持开启" / "始终执行"
4. 拉杆激活紫色方块
```
箭头方向必须一致（从紫→绿串连）。

## 常用搭配
```
第一个方块（循环）：execute 条件检测 + 主要逻辑
第二个方块（连锁）：重置计分板/状态
```
