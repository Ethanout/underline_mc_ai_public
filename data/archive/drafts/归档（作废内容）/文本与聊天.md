# 文本与聊天

## tellraw 格式（1.21.5+ NBT 组件）
```mcfunction
# 纯文本（1.21.5+ 文本组件为 NBT 对象，不再嵌套 JSON 字符串）
tellraw @a {"text":"Hello!","color":"gold","bold":true}

# 混合文本
tellraw @a [
  {"text":"You have ","color":"gray"},
  {"text":"5","color":"yellow"},
  {"text":" diamonds","color":"gray"}
]

# 悬停事件
tellraw @a {"text":"Hover me!","hover_event":{"action":"show_text","value":{"text":"Tooltip"}}}

# 点击事件
tellraw @a {"text":"Click me!","click_event":{"action":"run_command","value":"/say hi"}}
```

## 文本组件类型

### text — 纯文本
```mcfunction
tellraw @a {"text":"Hello!","color":"gold","bold":true}
```

### translate — 本地化/翻译键
```mcfunction
# 翻译键
tellraw @a {"translate":"block.minecraft.diamond_block"}

# 带参数替换（%s）
tellraw @a {"translate":"chat.type.announcement","with":[{"text":"Server"},{"text":"Hello!"}]}

# 带参数替换（%s）
tellraw @a {"translate":"%s,%s","with":[{"text":"你好"},{"text":"世界"}]}
```

### score — 显示计分板分数
```mcfunction
tellraw @a {"score":{"name":"@s","objective":"money","value":100}}
# name: 玩家名或 @s/@p（* 表示读者自己）
# objective: 计分板目标
# value: 可选，缓存值
```

### selector — 显示实体名（带事件监听）
```mcfunction
tellraw @a {"selector":"@p"}
tellraw @a {"selector":"@e[type=zombie,limit=3]"}
```

### keybind — 显示按键绑定
```mcfunction
tellraw @a {"keybind":"key.jump"}
tellraw @a {"keybind":"key.use"}
```

### nbt — 显示 NBT 数据
```mcfunction
# 实体数据
tellraw @a {"nbt":"Health","entity":"@s","interpret":true,"color":"green"}
# 方块数据
tellraw @a {"nbt":"Items","block":"0 0 0"}
# 存储数据
tellraw @a {"nbt":"money","storage":"ns:data"}
```

## 文本样式字段
```mcfunction
{"text":"...",
 "color":"red",                   # 颜色（named/hex：#RRGGBB）
 "shadow_color":"#FF0000FF",      # 阴影颜色（1.21.4+，RGBA hex）
 "font":"minecraft:default",       # 字体（default/alt/illageralt/uniform）
 "bold":true,                     # 粗体
 "italic":true,                   # 斜体
 "underlined":true,               # 下划线
 "strikethrough":true,            # 删除线
 "obfuscated":true,               # 乱码（混淆）
 "insertion":"/tp @s",            # Shift+点击插入到聊天框
 "extra":[...]                    # 子文本组件（继承父级样式）
}
```

## 交互事件
### hover_event — 悬停显示
```mcfunction
tellraw @a {"text":"Hover!","hover_event":{"action":"show_text","value":{"text":"Tooltip"}}}
tellraw @a {"text":"Show Item","hover_event":{"action":"show_item","id":"minecraft:diamond","count":1}}
tellraw @a {"text":"Show Entity","hover_event":{"action":"show_entity","type":"minecraft:pig","id":"<uuid>","name":{"text":"Pig"}}}
```

### click_event — 点击触发
```mcfunction
tellraw @a {"text":"Run cmd","click_event":{"action":"run_command","value":"/say hi"}}
tellraw @a {"text":"Suggest","click_event":{"action":"suggest_command","value":"/give @s diamond"}}
tellraw @a {"text":"Open URL","click_event":{"action":"open_url","value":"https://..."}}
tellraw @a {"text":"Copy","click_event":{"action":"copy_to_clipboard","value":"secret"}}

# 1.21.6+ 自定义点击事件（需 advancement listener）
tellraw @a {"text":"Custom","click_event":{"action":"minecraft:custom","value":"ns:my_event"}}
```

## 多用复合格式
```mcfunction
# 前文 + 分数 + 后文
tellraw @a [{"text":"余额：","color":"gray"},{"score":{"name":"@s","objective":"money"},"color":"gold"}]

# 翻译 + 选择器 + 文本
tellraw @a [{"translate":"commands.give.success.single","with":[{"selector":"@p"},{"text":"钻石","color":"aqua"}]}]

# 悬停 + 点击同一段
tellraw @a {"text":"点击传送",
  "color":"green","underlined":true,
  "hover_event":{"action":"show_text","value":{"text":"传送到出生点"}},
  "click_event":{"action":"run_command","value":"/spawn"}
}
```

## NBT 数据展示
```mcfunction
# 玩家数据
tellraw @a [{"text":"Health: "},{"nbt":"Health","entity":"@s","color":"red"}]

# 方块数据
tellraw @a [{"text":"Power: "},{"nbt":"power","block":"0 0 0"}]

# 存储
tellraw @a [{"text":"Balance: "},{"nbt":"money","storage":"mypack:data","color":"gold"}]

# 解释器
tellraw @a {"nbt":"Pos","entity":"@s","interpret":true,"color":"green"}
```

## Title / Actionbar / Subtitle
```mcfunction
# 主标题
title @a title {text:"胜利！",color:"yellow"}

# 副标题（必须先有 title title 才能一起显示）
title @a subtitle {text:"你击败了所有敌人",color:"gray"}

# 动作栏（物品栏上方小字）
title @a actionbar {text:"剩余弹药: 5/10",color:"red"}

# 时间控制
title @a times 10 60 20   # 淡入10t → 停留60t → 淡出20t

# 清除/重置
title @a clear
title @a reset
```

## 纯字符串简写
```mcfunction
tellraw @a "欢迎来到世界！"
```

## 文本组件格式化（存储为 NBT，不使用 JSON 字符串）
从 1.21.5 起，在 **NBT 数据存储**（如看板、物品组件、实体数据）中，文本组件不再是双重嵌套的 JSON 字符串，而是直接以 NBT 复合标签形式存储。

```mcfunction
# ❌ 旧的 NBT 存储写法（双重嵌套字符串）
CustomName: '{"text":"hello"}'

# ✅ 1.21.5+ NBT 存储写法（直接使用 NBT 对象）
CustomName: {text: "hello"}

# 备注：/tellraw 等命令的参数依然按照标准的 JSON 格式解析。
```
