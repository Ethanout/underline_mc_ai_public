# 物品相关

## 模板物品（Base Item）选型建议

制作自定义物品时，应选择交互性最弱的物品作为模板。

- **追溯指针 (recovery_compass) —— 最佳选择**：无右键方块交互、无合成配方、无生物吸引，数据极其纯净。
- **禁用组件的唱片 (music_disc_*)**：配合 `[!jukebox_playable]` 组件（1.21.5+）可完全屏蔽唱片机交互。
- **警告**：不要在非右键检测场景使用“胡萝卜钓竿”，因为它会吸引猪。

详见：[Q83 如何选取自定义物品模板与替换模型](../Q83_如何替换物品模型.md)

## 检测玩家手持物品
```mcfunction
# 用 items 子命令（1.20.5+，最快）
execute if items entity @s weapon.mainhand *[custom_data~{key:true}] run ...
execute if items entity @s weapon.offhand *[custom_data~{key:true}] run ...

# 用 if data（很慢，用于1.20.5-）
execute if data entity @s SelectedItem{id:"minecraft:stone"} run ...
execute if data entity @s Inventory[{Slot:-106b,id:"minecraft:stone"}] run ...


# 同时检测主副手
execute if items entity @s weapon *[custom_data~{key:true}] run ...
```

## 修改玩家手中物品
```mcfunction
# 清除某个
item replace entity @s weapon.mainhand with minecraft:air

# 增加 count
item modify entity @s weapon.mainhand mypack:add_count
```
#### mypack:add_count 修饰器定义

`data/<namespace>/item_modifier/add_count.json`
```json
{
  "function": "minecraft:set_count",
  "count": 1,
  "add": true
}
```

## 给予物品
```mcfunction
# 组件格式：物品ID[组件1=值,组件2=值,...]
# 注意：1.21.5+ 强制要求 JSON 文本组件使用严格对象格式，且 enchantments 已简化（取消 levels 层）
give @s apple[custom_name='{"text":"金苹果"}',lore=['{"text":"传说级物品"}'],enchantments={sharpness:5}]

# 详细组件示例
give @s carrot_on_a_stick[
  custom_data={id:"special"},
  custom_name='{"text":"避雷针","color":"red","italic":false}',
  lore=['{"text":"引雷装置","color":"gray"}','{"text":"按下右键被雷劈","color":"gray"}'],
  item_model="lightning_rod"
]


# 禁用组件用 !
give @s apple[!consumable]

# 用战利品表（推荐）
loot give @s loot mypack:special_item
```
#### mypack:special_item 战利品表定义

`data/<namespace>/loot_table/special_item.json`
```json
{
  "pools": [
    {
      "rolls": 1,
      "entries": [
        {
          "type": "minecraft:item",
          "name": "minecraft:diamond",
          "functions": [
            { "function": "minecraft:set_custom_data", "tag": "{id:\"special\"}" },
            { "function": "minecraft:set_name", "name": {"text":"特殊钻石","color":"gold","italic":false} }
          ]
        }
      ]
    }
  ]
}
```

## 物品组件：常用组件列表
完整列表见 [Minecraft Wiki 数据组件格式](https://minecraft.wiki/w/Data_component_format)。
```mcfunction
custom_data={key:"value"}       # 自定义数据（标记物品）
custom_name={text:"名称"}       # 自定义名称（文本组件）
item_name={text:"名称"}         # 覆盖原名（不显示斜体）
lore=["行1","行2"]              # 描述
item_model="namespace:model"   # 物品模型
enchantments={sharpness:5}      # 附魔（1.21.5+ 取消 levels 嵌套）
consumable={consume_seconds:1.6,animation:"eat"} # 可消耗
jukebox_playable={song:"..."}   # 唱片播放组件（可 ! 禁用）

attribute_modifiers=[...]       # 属性修饰符
food={nutrition:6,saturation:8,can_always_eat:true} # 食物属性
tool={rules:[],default_mine_time:1.0}  # 挖掘工具属性
damage=10                       # 耐久损伤
max_damage=100                  # 最大耐久
unbreakable={}                  # 不可破坏
rarity="epic"                   #  rarity: common/uncommon/rare/epic
use_cooldown={seconds:5}        # 使用冷却
equippable={slot:"head"}        # 可装备到指定栏位
item_model="namespace:model"   # 模型覆盖
!consumable                     # 禁用可消耗
!enchantment_glint              # 隐藏附魔闪光
!tooltip_display                # 隐藏工具提示
```

## 属性修饰符格式
```mcfunction
give @s iron_sword[attribute_modifiers=[
  {type:"attack_damage",  id:"a", slot:"hand", amount:0.5, operation:"add_multiplied_base"},
  {type:"movement_speed", id:"m", slot:"hand", amount:0.1, operation:"add_multiplied_base"}
]]
```
- `type`：属性 ID（`attack_damage`, `movement_speed`, `scale` 等）
- `id`：唯一标识，不要重复（与 `attribute modifier add` 共用命名空间）
- `slot`：`hand`/`mainhand`/`offhand`/`head`/`chest`/`legs`/`feet`/`any`
- `amount`：数值（浮点）
- `operation`：`add_value`（加减） / `add_multiplied_base`（加法百分比叠加） / `add_multiplied_total`（乘法百分比叠加）

## 物品组件常用操作
```mcfunction
# 添加数据
data modify entity @s SelectedItem.components."minecraft:custom_data" merge {mykey:"myvalue"}

# 读取
data get entity @s SelectedItem.components."minecraft:custom_data"

# 检测
execute if data entity @s SelectedItem.components."minecraft:custom_data"{mykey:"myvalue"} run ...
```

## 遍历玩家背包
```mcfunction
# 限制 8 格以免卡顿
execute store result score #i tmp run data get entity @s Inventory
scoreboard players set #max tmp 8
scoreboard players operation #len tmp = #i tmp
execute if score #i tmp < #len tmp run function my:inventory/loop
```

## 瞬间给予大量物品（Bundle 展开法）

> 发现者：g4b8o，thomasdelacombe

利用 Bundle 的 `bundle_contents` 组件直接包含物品列表，配合低生命值召唤使 Bundle 瞬间死亡掉落全部内容：

```mcfunction
$summon minecraft:item ~ ~ ~ {Item:{id:bundle,components:{bundle_contents:$(storage_list)}},Fire:200,Health:1}
```

- Bundle 生成时生命值仅 1，立即死亡弹出全部物品
- 省去遍历每个物品的开销
- 适合列表中包含大量物品的场景

## 对全背包应用物品修饰器

利用战利品表的 `slot_range` 获取背包所有槽位，将修饰器应用到每个物品上：

```mcfunction
/loot replace entity @s container.0 loot {
  pools:[{rolls:1,entries:[{type:loot_table,value:"namespace:inventory"}]}],
  functions:[{function:set_name,name:EXAMPLE}]
}
```

需在数据包中定义 `inventory` 战利品表处理空槽位（向空槽插入物品然后立即丢弃）。

## 无限消耗品（组件切换）

在 `consume_item` 进度奖励函数中，即将被消耗的物品实际仍然存在。修改其组件可阻止移除：

```mcfunction
# 物品条件：consumable, custom_data~{无限:1b}
data modify entity @s SelectedItem.components."minecraft:custom_data".无限 set value 0b
data modify entity @s SelectedItem.components."minecraft:custom_data".无限 set value 1b
```
注意：物品不应含 `use_remainder` 组件；组件值必须实际变化（否则客户端视觉不同步）。

## 背包检测：if items vs clear 0 性能对比

| 方法 | 库存为空 | 少量匹配 | 合成格有物品 |
|------|:---:|:---:|:---:|
| `execute if items` 穷举 | 最慢（全跑完） | 正常 | 正常 |
| `clear @s ... 0` | 最快 | 正常 | **慢 ~10 倍** |

- `if items` 完全安全，不会意外操作物品
- `clear 0` 稳定且通常更快，但玩家合成格有物品时性能急剧下降
- 建议：合成格无关时用 `clear 0`，否则用 `if items`
