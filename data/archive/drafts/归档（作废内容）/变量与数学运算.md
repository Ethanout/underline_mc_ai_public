# 变量与数学运算

## 计分板运算
```mcfunction
# 取值
execute store result score @s var run scoreboard players get @s var

# 加法
scoreboard players add @s var 5

# 减法
scoreboard players remove @s var 5

# 除法（整数截断）
scoreboard players operation @s result /= 2 const

# 乘法
scoreboard players operation @s result *= 2 const

# 模运算
scoreboard players operation @s result %= 5 const

# 赋值
scoreboard players operation @s result = @p input
```

## 定点数小数
```mcfunction
# 移位 1000 倍存储小数（3 位精度）
# 存 3.141 → 3141
scoreboard players set @s pi 3141

# 乘 2
scoreboard players operation @s pi *= 2 const  # 6282

# 显示时除以 1000
# 1.5 * 1000 = 1500
```

## 随机数

### 官方命令法（1.20.2+，推荐）
使用内置 `/random` 命令，直接将随机值存入计分板。
```mcfunction
# 产生 1~10 的随机数存入 @s 的 random 目标
random roll 1..10

# 产生 0~99 的随机值并存入变量
execute store result score #val tmp run random value 0..99

# 使用特定随机序列（保证可重复性）
random roll 1..6 my_sequence
```

### 战利品表法（整数范围，1.20.2 之前）
```json
{
  "function": "minecraft:set_count",
  "count": {
    "type": "minecraft:uniform",
    "min": 1.0,
    "max": 10.0
  }
}
```
然后用 `execute store result score @s random run loot ...` 取。
<HAS_PROBLEM:应该先生成一个常态的物品展示实体，然后loot掉container.0，然后execute store result score run data get entity或者data modify from，而且一般会去修改幸运值而不是物品数量>

### UUID 法（1.13+）
利用新生成实体的 UUID 作为随机源，无需额外文件：
```mcfunction
# load
scoreboard objectives add random dummy
scoreboard objectives add range dummy

# 生成 0~5 随机数
scoreboard players set @s range 6
summon marker ~ ~ ~ {Tags:["rng_uuid"]}
execute store result score @s random run data get entity @e[type=marker,tag=rng_uuid,limit=1] UUID[0] 1
scoreboard players operation @s random %= @s range
kill @e[type=marker,tag=rng_uuid]
```
每次生成/销毁实体，性能开销大，仅限低频率使用（1.20.2- 无 `/random` 时的备选）。

### LCG 法（伪随机数生成器）

纯计分板运算，无需实体，速度快：
```mcfunction
# load
scoreboard objectives add rng dummy
scoreboard players set 1103515245 rng 1103515245
scoreboard players set 12345 rng 12345

# tick（每次调用产生下一个伪随机数）
scoreboard players operation seed rng *= 1103515245 rng
execute store result score output rng scoreboard players operation seed rng += 12345 rng
```
适合高频调用，但奇偶位随机性不好，有需要可以在output rng之后除以4。
<HAS_PROBLEM:范围没讲清楚，以及之后还要%=一下限制数字>

## 计时器

### 倒计时
```mcfunction
# load
scoreboard objectives add timer dummy

# tick
scoreboard players remove @a[scores={timer=1..}] timer 1

# 启动
scoreboard players set @s timer 40  # 2秒倒计时

# 检测到时
execute if score @s timer matches 0 run ...
```

### 正计时（用于音效序列等）
```mcfunction
# load
scoreboard objectives add seq dummy

# tick
scoreboard players add @a[scores={seq=1..}] seq 1

# 启动
scoreboard players set @s seq 1

# 按帧触发
# data/example/function/sound/seq_tick.mcfunction
execute if score @s seq matches 1 run playsound entity.experience_orb.pickup master @s ~ ~ ~ 1 1
execute if score @s seq matches 11 run playsound entity.experience_orb.pickup master @s ~ ~ ~ 1 0.5
execute if score @s seq matches 11.. run scoreboard players set @s seq 0  # 结束

# 停止
scoreboard players set @s seq 0
```

### 降频（取模）
```mcfunction
# load
scoreboard objectives add const dummy
scoreboard objectives add clock dummy
scoreboard players set 5 const 5

# tick
scoreboard players add #game_time clock 1
scoreboard players operation #mod clock %= 5 const

# 每 5 tick 运行一次
execute if score #mod clock matches 0 run function ns:heavy_task
# 错开
execute if score #mod clock matches 1 run function ns:other_task
```

## 先乘后除以防止溢出

**原理**：计分板是 32 位有符号整数，`x * y / z` 中 `x * y` 可能溢出（超出 ±2147483647）。将乘法拆解或利用模运算分部计算可避免溢出。

参考库：`u.math`，提供完整的乘除模防溢出函数。目前这是社区内速度最快的实现，缩放除法平均约 10 条 scb add 消耗，最佳情况仅 3 条左右。自己实现几乎不可能比它更快。

### 缩放除法（定点数小数）

计分板存整数，但需要小数结果时，先乘 10/100/1000 再除：

```mcfunction
# x = 212345678 * 10 // 474747 = 4472（即 44.72 的整数部分 ×100）
scoreboard players set x u.variable 212345678
scoreboard players set y u.variable 474747
function u.math:x/mult_10_divmod_y

# x = 212345678 * 100 // 474747 = 44728
function u.math:x/mult_100_divmod_y

# x = 212345678 * 1000 // 474747 = 447281
function u.math:x/mult_1000_divmod_y

```

### 快速乘除取模（z ≤ 46341 时最快）

```mcfunction
# LOAD
scoreboard objectives add u.variable dummy

# 输入
scoreboard players set x u.variable 1234567
scoreboard players set y u.variable 7654321
scoreboard players set z u.variable 40000

# x = 1234567 * 7654321 // 40000 = 236244302
# y = 1234567 * 7654321 %  40000 = 34007
function u.math:x/fast_mult_y_divmod_z

# 取结果
scoreboard players get x u.variable
scoreboard players get y u.variable
```

约束：`x, y, z ≥ 0`，`z ≤ 46341`。

### 通用乘除取模（全范围）

```mcfunction
# 输入（支持负数）
scoreboard players set x u.variable 1234567
scoreboard players set y u.variable -7654321
scoreboard players set z u.variable 100000

# x = 1234567 * -7654321 // 100000 = -94497722
# y = 1234567 * -7654321 %  100000 = 85993
function u.math:x/mult_y_divmod_z
```

约束：`x, y, z ≥ -2147483647`；若 `|z| ≥ 46342`，需 `2(|z|-1) + |x| ≤ 2174783647`。



## 浮点数求和（sum 数值提供器）

通过 `set_custom_model_data` 的 `sum` 数值提供器对 float 列表求和，无需类型转换。

```mcfunction
# 放置占位物品
# 前提：0 0 0 处有一个任意物品作为容器

$item modify block 0 0 0 container.0 {function:"minecraft:set_custom_model_data",floats:{values:[{type:"minecraft:sum",summands:$(in)}],mode:"replace_section"}}
data modify storage ns:out set from block 0 0 0 Items[0].components."minecraft:custom_model_data".floats[0]
```

### 调用

```mcfunction
function ns:fsum {in:[3.1415f,-2.7182f,1.6180f]}
# storage ns:out → 2.0413f

function ns:fsum {in:[1b,2s,3i,4l,5f,6.0000000001d]}
# 异构列表，输入在求和前统一转为 float → 21.0f
```

### 已知行为
- 输入支持异构数字列表（byte/short/int/long/float/double），求和前转为 float
- 结果覆盖完整 float 范围（含超出 float 最大值的 `Infinityf`）
- 用存储值替代宏参数可进一步提速
- 受宏开销影响速度较慢，但一指令内完成任意数量加法

### 性能参考（oligo 基准测试，3000次/tick）
| 方法 | 平均ms | 最高ms |
|------|:---:|:---:|
| baseline（空函数） | 5 | 7 |
| scoreboard 整数加法 | 6 | 8 |
| **fadd（sum数值提供器）** | **13** | **23** |
| 云计算（cc） | 23 | 28 |
| 实体传送（gm） | 34 | 44 |

fadd 是最快的浮点数加法方法，约为云计算的 1.7 倍，一次操作相当于 2-3 次计分板整数加法，且是唯一能覆盖完整 float 范围的方法。

## 余弦近似

角度制：`cos(d) = 1 - 5 / ((180/d)² + 1)`

弧度制：`cos(x) = 1 - 5 / ((π/x)² + 1)`

无函数/数据包依赖，几条记分板运算即可完成，适用于精度不高于0.005的场景。

## 浮点数代数运算与四舍五入（storage int 技巧）

对任意 storage 的 int 做 `(x*a-1)*b` 运算（利用 `data get` 的浮点截断，本质是 `int(x*a ± ε) * b`）：
int为向下取整。

```mcfunction
# x 为正数时：
execute store result storage io var int b run data get storage io var a-.0000000001

# x 为负数时：
execute store result storage io var int b run data get storage io var a+.0000000001
```

例：`x*3-5` → `b=5`, `a=0.6`
```mcfunction
execute store result storage io var int 5 run data get storage io var .5999999999
# x=10: 10*0.5999999999=5.999999999→5, 5*5=25 ✓
# x=-10: -10*0.6000000001=-6.000000001→-7, -7*5=-35 ✓
```

注意：x 不能为 0。

### 应用：四舍五入

`(x*a-1)*b` 取 `a=-2, b=-0.5` 等价于 `int(x + 0.5)`（即四舍五入到整数）：
int为向下取整。

```mcfunction
# x 为正数：scale = -2.0000000001
execute store result storage io var int -0.5 run data get storage io var -2.0000000001
# 流程：data get → x × (-2.0000000001) → floor → × (-0.5) → int 存
# x=7  → -14.0000000007 → floor -15  → 7.5  → 7
# x=7.4→ -14.80000000074→ floor -15  → 7.5  → 7
# x=7.5→ -15.00000000075→ floor -16  → 8    → 8
# x=8  → -16.0000000008 → floor -17  → 8.5  → 8
```
