# 调试方法

## 输出调试（tellraw）
```mcfunction
# 查看分数
tellraw @a ["调试: ", {"score":{"name":"@s","objective":"test"}}]

# 查看 NBT
tellraw @a [{"text":"Storage: "},{"nbt":"data.inv","storage":"ns:io"}]
tellraw @a [{"text":"背包首位: "},{"nbt":"Inventory[0]","entity":"@s"}]

# 多行
tellraw @a [{"text":"--- 调试 ---\n"},{"score":{"name":"@s","objective":"test"}},"\n",{"nbt":"Inventory[0]","entity":"@s"}]
```

## 视觉调试（粒子标记）
```mcfunction
particle cloud ~ ~ ~ 0 0 0 0 0 force
particle end_rod ~ ~ ~ 0 0 0 0 0 force
particle electric_spark ~ ~ ~ 0 0 0 0 0 force
```
在递归函数中插入粒子可以可视化执行路径（如射线检测）。

## 侧边栏监视
```mcfunction
scoreboard objectives setdisplay sidebar test
```

## 性能分析

### F3+2 性能监视器
- 左边是渲染（显卡）
- 右边是逻辑（CPU），应保持在白框 1/5 以下（< 10ms）

### F3+L 火焰图
按 F3+L 录制 10 秒，自动生成 profiler 报告压缩包，解压后查看 `server/profiling` 下的 HTML 火焰图。

### /tick sprint 压力测试
```mcfunction
/tick sprint 10s
```
在虚空存档把命令复制 1000 次放大消耗，对比空载 ms/tick：
```
(测试ms - 空载ms) / 1000 = 单次运行消耗时间
```

### Bookshelf Dump 调试模块
```mcfunction
# 查分数
function #bs.dump:var {var: ["@s test"]}
# 查 Storage
function #bs.dump:var {var: ["storage ns:io {}"]}
# 查实体 NBT
function #bs.dump:var {var: ["entity @s Inventory[0]"]}
# 带标签
function #bs.dump:var {var: { "分数1": "@s test1", "分数2": "@s test2" }}
```
