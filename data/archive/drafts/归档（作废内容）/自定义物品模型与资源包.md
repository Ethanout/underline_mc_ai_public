# 自定义物品模型与资源包

1.21.4+ 可通过独立物品定义文件实现自定义模型，不再需要覆盖原版模型。

## 资源包结构
```
<resourcepack>/
├── pack.mcmeta
├── pack.png
└── assets/
    └── <namespace>/
        ├── models/item/      # 模型文件（.json，形状）
        ├── textures/item/    # 材质文件（.png）
        └── items/            # 物品定义文件（大脑，决定何时显示哪个模型）
```

## pack.mcmeta
```json
{
  "pack": {
    "description": "平行线教程资源包",
    "pack_format": 63,
    "supported_formats": [56, 63]
  }
}
```

## 三个核心概念
- **Models（形状）**：`assets/<namespace>/models/item/<name>.json`
- **Texture（材质）**：`assets/<namespace>/textures/item/<name>.png`
- **Items（大脑）**：`assets/<namespace>/items/<name>.json` — 编写逻辑决定何时用哪个模型

## 基础调用
```mcfunction
give @s stick[item_model="<namespace>:<name>"]
```

底层 `items/<name>.json`：
```json
{
  "model": {
    "type": "minecraft:model",
    "model": "<namespace>:item/<name>"
  }
}
```

## 模型映射类型

### 直接型（model）
固定显示一个模型。

### 枚举型（select）
根据有限状态切换，如手上/背包显示不同：
```json
{
  "model": {
    "type": "minecraft:select",
    "property": "minecraft:display_context",
    "cases": [
      { "when": "gui", "model": { "type": "minecraft:model", "model": "ns:item/icon" } }
    ],
    "fallback": { "type": "minecraft:model", "model": "ns:item/3d" }
  }
}
```

### 布尔型（condition）
根据是非条件二选一：
```json
{ "type": "minecraft:condition", "property": "minecraft:using_item", "on_true": ..., "on_false": ... }
```

### 数值型（range_dispatch）
根据连续数值分段切换，用于蓄力动画：
```json
{
  "type": "minecraft:range_dispatch",
  "property": "minecraft:use_duration",
  "scale": 0.05,
  "entries": [
    { "threshold": 0.0, "model": { "type": "minecraft:model", "model": "ns:item/staff_0" } },
    { "threshold": 0.5, "model": { "type": "minecraft:model", "model": "ns:item/staff_1" } }
  ],
  "fallback": { "type": "minecraft:model", "model": "ns:item/staff_0" }
}
```

### 复合型（composite）
叠加多个模型，可嵌套逻辑，如身体+独立翅膀动画：
```json
{
  "type": "minecraft:composite",
  "models": [
    { "type": "minecraft:model", "model": "ns:item/body" },
    { "type": "minecraft:condition", "property": "minecraft:keybind_down", "keybind": "key.jump", "on_true": ..., "on_false": ... }
  ]
}
```

## 支持的长按检测物品
```mcfunction
give @s stick[consumable={consume_seconds:2147483647},item_model="ns:my_staff"]
```
`consumable` + 极大秒数 = 可长按但不消耗的物品。
