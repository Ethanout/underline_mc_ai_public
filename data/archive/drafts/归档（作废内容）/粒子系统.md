# 粒子系统

## 常用粒子命令
```mcfunction
# 简单粒子
particle minecraft:flame ~ ~ ~ 0 0 0 0 1

# 带颜色
particle entity_effect{color:[1.0,0.5,0.0,1.0]} ~ ~ ~ 0 0 0 0 1

# 物品粒子
particle item minecraft:diamond ~ ~ ~ 0 0 0 0 1

# 方块粒子
particle block minecraft:stone ~ ~ ~ 0 0 0 0 1

# 区域（使用 area/spread）
particle minecraft:flame ~ ~ ~ 3 1 3 0.05 50
```

## 粒子参数
```mcfunction
particle <name> <pos> <dx> <dy> <dz> <speed> <count> [force|normal] [players]
```
- `force`：无视视锥裁剪，肯定可见
- `normal`：默认行为，不可见时不生成
- `count > 0`：固定数量
- `count = 0`：单发射

## 数据粒子（着色器通讯通道）
```mcfunction
# alpha=0.114 标记为数据粒子
particle entity_effect{color:[1.0,0.5,0.0,0.114]} ~ ~ ~
```
着色器端：检测 `Color.a > 0.113 && Color.a < 0.115`

## 粒子类型参考
| 类型 | 描述 | 数据格式 |
|------|------|----------|
| `entity_effect` | 彩色方形粒子 | `{color:[R,G,B,A]}` |
| `item` | 物品粒子 | `item <id>` |
| `block` | 方块粒子 | `block <id>` |
| `dripping` | 滴落粒子 | 无 |
| `dust` | 红石粉粒子 | `{color:[R,G,B],scale:N}` |
| `dust_color_transition` | 渐变粉尘 | `{from_color:[R,G,B],to_color:[R,G,B],scale:N}` |
| `vibration` | 振动粒子 | `{destination:{type:"block",pos:[x,y,z]}}` |
| `sculk_charge` | 循声粒子 | `{roll:float}` |

## 粒子速度与含义
```mcfunction
# speed > 0：粒子运动速度（不同粒子类型含义不同）
# 火焰粒子：speed 影响射程
# 实体效果：speed 完全无影响（color 在数据中）
```

## 粉尘粒子（Dust）详细
```mcfunction
# 红色大粒子
particle dust{color:[1.0,0.0,0.0],scale:2.0} ~ ~1 ~ 0.5 0.5 0.5 0 10
```
- `color`：RGB 颜色，每分量 0.0~1.0
- `scale`：粒子大小

## 方块/物品碎屑
```mcfunction
# 金块碎屑
particle block{block_state:"minecraft:gold_block"} ~ ~1 ~ 0.5 0.5 0.5 0 20

# 苹果碎屑
particle item{item:"minecraft:apple"} ~ ~1 ~ 0.2 0.2 0.2 0.1 10
```

## 调试用粒子（force 模式无视距离）
```mcfunction
particle cloud ~ ~ ~ 0 0 0 0 0 force
particle end_rod ~ ~ ~ 0 0 0 0 0 force
particle electric_spark ~ ~ ~ 0 0 0 0 0 force
```
