# 队伍与聊天格式

## 队伍基础操作
```mcfunction
# 创建
team add <id> <显示名称(文本组件)>
team add red {"text":"红队","color":"red"}

# 加入/离开
team join <id> @s
team leave @s

# 查询/清空/删除
team list
team list red
team empty red
team remove red
```

## 队伍选项

### 战斗相关
```mcfunction
# 关闭友伤
team modify red friendlyFire false

# 死亡信息显示
team modify red deathMessageVisibility never  # 完全隐藏
# hideForOtherTeams / hideForOwnTeam / always
```

### 物理相关
```mcfunction
# 关闭碰撞
team modify red collisionRule never
# never / always / pushOwnTeam / pushOtherTeams
```

### 视觉相关
```mcfunction
# 隐藏头顶名字
team modify red nametagVisibility never

# 看见隐身队友
team modify red seeFriendlyInvisibles true

# 队伍颜色（名字/发光/列表）
team modify red color red
```

### 聊天格式化
```mcfunction
# 前缀/后缀
team modify red prefix {"text":"[红队] ","color":"red"}
team modify red suffix {"text":" ❤","color":"red"}
```

## 自定义聊天类型（chat_type）

### 文件位置
`data/<namespace>/chat_type/<name>.json`

### 核心字段
```json
{
  "chat": {
    "translation_key": "<%s> %s",
    "parameters": ["sender", "content"]
  },
  "narration": {
    "translation_key": "chat.type.text",
    "parameters": ["sender", "content"]
  }
}
```
- `translation_key`：消息模板，`%s` 占位符
- `parameters`：填入占位符的参数的顺序

### 格式化代码（§）
```mcfunction
"translation_key": "§c[%s]§r: %s"
```
- `§c` 红色名字 → `§r` 重置 → `: %s` 白色消息
- 颜色：`§0`-`§f`, `§a`-`§f`
- 样式：`§l` 粗体 `§o` 斜体 `§k` 乱码 `§r` 重置

### 注意事项
- 聊天类型属于注册表数据，**不可 `/reload`**，需重进世界
- 格式化代码已被 Mojang 标记弃用，未来可能移除，建议改用文本组件

## 实战：跑酷地图配置
```mcfunction
team add runners {"text":"跑酷选手","color":"aqua"}
team modify runners color aqua
team modify runners friendlyFire false
team modify runners collisionRule never
team modify runners seeFriendlyInvisibles true
team modify runners prefix {"text":"[选手] ","color":"gray"}
team join runners @p
```
