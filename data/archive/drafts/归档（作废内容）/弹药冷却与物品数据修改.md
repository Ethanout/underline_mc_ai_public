# 弹药冷却与物品数据修改

## 物品数据流转三步走

### 读 → 算 → 写
```
物品(custom_data) ── data get ──→ 记分板/Storage
                                      ↓ 计算
物品(custom_data) ←─ item modify ── Storage
```

## 读取物品数据到记分板
```mcfunction
execute store result score ammo tmp run data get entity @s SelectedItem.components."minecraft:custom_data".ammo
```

## 写回物品数据（item modifier + storage）
### 1. 存入 Storage
```mcfunction
execute store result storage ns:io temp_ammo int 1 run scoreboard players get ammo tmp
```

### 2. Item Modifier 定义
`data/<namespace>/item_modifier/update_ammo.json`
```json
{
  "function": "minecraft:copy_custom_data",
  "source": { "type": "minecraft:storage", "source": "ns:io" },
  "ops": [
    { "source": "temp_ammo", "target": "ammo", "op": "replace" }
  ]
}
```

### 3. 执行写回
```mcfunction
item modify entity @s weapon.mainhand ns:update_ammo
```

## 全局冷却系统（gametime）
```mcfunction
# 当前时间
execute store result score time tmp run time query gametime

# 读取解禁时间
execute store result score reload_recovery tmp run data get entity @s SelectedItem.components."minecraft:custom_data".reload_recovery

# 如果还在冷却，截断
execute if score reload_recovery tmp > time tmp run return 0

# 计算新的解禁时间
scoreboard players operation temp_time tmp = time tmp
scoreboard players operation temp_time tmp += reload_cd tmp

# 存入并写回
execute store result storage ns:io temp_recovery int 1 run scoreboard players get temp_time tmp
data modify storage ns:io temp_ammo set value 10
item modify entity @s weapon.mainhand ns:update_ammo
```

## 物品初始数据
```mcfunction
give @s stick[custom_data={id:"gun",ammo:10,reload_cd:40,reload_recovery:0}]
```

## 谓词检测玩家输入
`data/<namespace>/predicate/is_sneaking.json`
```json
{
  "condition": "minecraft:entity_properties",
  "entity": "this",
  "predicate": {
    "type_specific": { "type": "minecraft:player", "input": { "sneak": true } }
  }
}
```
用法：
```mcfunction
execute as @a if predicate ns:is_sneaking run ...
```

## 右键+物品检测（枪械触发）
```mcfunction
# load
scoreboard objectives add click_rmb used:carrot_on_a_stick

# tick
execute store result score time tmp run time query gametime
execute as @a if score @s click_rmb matches 1.. if items entity @s weapon.mainhand stick[custom_data~{id:"gun"}] run function ns:gun/shoot
```
