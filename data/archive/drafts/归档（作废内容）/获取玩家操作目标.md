# 获取玩家操作目标 (Raycasting)

## 方案 A：`on target` 子命令 (1.20.5+)

这是检测玩家准心所指实体的最快方法：

```mcfunction
# 检测玩家正在看的实体（10格内）
execute as @a at @s on target run say 我正在看 @s
```
- **优点**：原生支持，性能极高。
- **缺点**：不能检测方块，距离限制较死。

## 方案 B：精密射线检测 (Raycasting)

用于检测方块或特定距离的实体。

### 1. 递归函数 `raycast.mcfunction`
```mcfunction
# 步进
particle portal ~ ~ ~ 0 0 0 0 1
execute if block ~ ~ ~ #minecaft:passable run function ns:raycast/loop
```

### 2. 循环 logic `loop.mcfunction`
```mcfunction
# 向前推进 0.1 格
positioned ^ ^ ^0.1 run function ns:raycast/step

# 步进函数 step
# 检测实体
execute as @e[type=!player,distance=..0.5,limit=1] run function ns:on_hit_entity
# 检测方块
execute unless block ~ ~ ~ #minecraft:passable run function ns:on_hit_block
# 距离截断
execute if score #dist tmp matches ..100 run function ns:raycast/loop
```

## 方案 C：交互实体 (Interaction Entity)

给实体套一个"碰撞箱"：
```mcfunction
summon interaction ~ ~ ~ {width:2,height:2,Tags:["target"]}
```
- 检测右键：`execute as @e[type=interaction] if data entity @s attack run ...`
- 检测左键：`execute as @e[type=interaction] if data entity @s interaction run ...`
