## 状态机检测（上升沿/下降沿）

用半减状态机在 `#tick` 中检测"刚按下"和"刚释放"（详见[长按检测](../1_最佳实践与设计决策/长按检测.md)）：

### 减半法（+4 变体）
```mcfunction
scoreboard players operation @s state /= 2 const
execute if predicate my:input/jump run scoreboard players add @s state 4
execute if score @s state matches 2 run function my:on_press
execute if score @s state matches 1 run function my:on_release
```
| 值 | 含义 |
|----|------|
| 2 | 开始按下 |
| 3 | 正在长按 |
| 1 | 松开 |
| 0 | 无操作 |

### 防抖变体（+6）
加 6 而非 4 时，3=按下，4~5=防抖保持，1=释放，2=过渡。适合进度检测可能断触的场景。

## 前后帧法（两个记分板）

对比"上一刻"和"这一刻"的值来判定状态变化。

```mcfunction
# load
scoreboard objectives add rmb_now dummy
scoreboard objectives add rmb_prev dummy

# tick
execute as @a at @s run function ns:input/player_tick

# player_tick
execute if score @s rmb_prev matches 0 if score @s rmb_now matches 1 run say 开始
execute if score @s rmb_prev matches 1 if score @s rmb_now matches 1 run say 按住
execute if score @s rmb_prev matches 1 if score @s rmb_now matches 0 run say 松开
scoreboard players operation @s rmb_prev = @s rmb_now
scoreboard players set @s rmb_now 0
```
状态更新顺序必须为：检测 → 存 prev → 清 now，否则逻辑混乱。
