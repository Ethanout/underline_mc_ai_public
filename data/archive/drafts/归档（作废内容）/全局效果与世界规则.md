# 全局效果、世界规则与游戏机制

## 天气控制
```mcfunction
weather clear [duration]     # 晴天
weather rain [duration]      # 下雨/下雪
weather thunder [duration]   # 雷暴
```

## 时间控制
```mcfunction
time set day                 # 1000 ticks (6:00)
time set noon                # 6000 ticks (12:00)
time set night               # 13000 ticks (6:00pm)
time set midnight            # 18000 ticks (0:00)
time add <ticks>             # 增加时间
time query daytime           # 查询一天中的时间
time query gametime          # 查询游戏总时间
```

## gamerule
```mcfunction
gamerule doDaylightCycle false       # 停止昼夜循环
gamerule doWeatherCycle false        # 停止天气循环
gamerule doMobSpawning false         # 阻止自然生物生成
gamerule keepInventory true          # 死亡不掉落
gamerule randomTickSpeed 0           # 停止随机方块更新
gamerule doEntityDrops false         # 阻止实体掉落物
gamerule mobGriefing false           # 防止苦力怕等破坏地形
gamerule commandBlockOutput false    # 关闭命令方块输出
```

## 玩家规则
```mcfunction
# 单人游戏提升为 OP
op <player>
deop <player>

# 游戏模式
gamemode creative @p
gamemode survival @p
gamemode adventure @p
gamemode spectator @p

# 难度
difficulty peaceful
difficulty easy
difficulty normal
difficulty hard
```

## 世界边界
```mcfunction
worldborder set 100              # 设定边界大小
worldborder center ~ ~           # 设定边界中心
worldborder add 10               # 增加边界大小
worldborder damage buffer 0      # 边界伤害缓冲
worldborder damage amount 0.2    # 边界伤害量
```

## 游戏规则修改（结合数据包）
```mcfunction
# #minecraft:load 时设置
execute unless score _setup bs.data matches 1 run {
  gamerule doDaylightCycle false,
  gamerule doWeatherCycle false,
  scoreboard players set _setup bs.data 1
}
```

## 自然生成控制
```mcfunction
# 禁用特定生物生成（通过标签）
# data/minecraft/tags/entity_type/disable_spawns.json
{ "values": ["minecraft:creeper", "minecraft:phantom"] }
```
（注意：这个方法只在 1.21.5+ 有效）

## 声音控制
```mcfunction
stopsound @a *          # 停止所有声音
playsound entity.experience_orb.pickup master @p ~ ~ ~ 1 1 1
```
完整格式：`playsound <声音ID> <声道> <目标> <位置> <音量> <音调> <最小音量>`
- 声道：`master`, `music`, `record`, `weather`, `block`, `hostile` 等
- 音调：0.5（低沉）~ 2.0（尖锐）
- 音量 > 1：增加传播距离而非音量
- 最小音量：0~1，距离太远时补偿音量

## 队伍系统（Team）
```mcfunction
# 创建队伍
team add red {"text":"红队","color":"red"}
team join red @p

# 常用选项
team modify red friendlyFire false           # 关闭友伤
team modify red collisionRule never          # 关闭碰撞（跑酷）
team modify red nametagVisibility never      # 隐藏名字
team modify red seeFriendlyInvisibles true   # 看见隐身队友
team modify red color red                    # 队伍颜色
team modify red prefix {"text":"[红队] "}    # 聊天前缀
```

## 自定义聊天类型（chat_type）
`data/<namespace>/chat_type/<name>.json`
```json
{
  "chat": {
    "translation_key": "<%s> %s",
    "parameters": ["sender", "content"]
  }
}
```
注意：聊天类型属于注册表数据，需重进世界生效。
