# 玩家数据持久化与同步

## Player ID 系统

给每个玩家分配唯一计分板 ID，用于索引 Storage 数据库中的玩家数据：

```mcfunction
# load
scoreboard objectives add id dummy
scoreboard objectives add ns dummy
scoreboard players set id ns 0

# 首次加入分配 ID（advancement tick 触发）
# function first_join
execute unless score @s id matches -2147483648.. store result score @s id run scoreboard players add id ns 1
```

## Storage 数据库模式

用 Storage 存储所有玩家数据的通用方案：

```json
{
  "data": [
    { "id": 1, "data": { "职业": "战士", "等级": 10, "inv": [] } },
    { "id": 2, "data": { "职业": "法师", "等级": 5, "inv": [] } }
  ]
}
```

### NBT 路径列表筛选

```mcfunction
# 按 ID 查找并修改
data modify storage ns:io data[{id:2}].data.职业 set value "法师"
```

## 宏：解决路径无法动态写分数的问题

由于 NBT 路径不支持动态计分板值，需要用宏传参。

### 写入入口
`data/<namespace>/function/data/modify.mcfunction`
```mcfunction
execute unless score @s id matches -2147483648.. store result score @s id run scoreboard players add id ns 1
execute store result storage ns:io id int 1 run scoreboard players get @s id
function ns:data/modify/macro with storage ns:io
```

### 宏函数
`data/<namespace>/function/data/modify/macro.mcfunction`
```mcfunction
$data modify storage ns:io data[{id:$(id)}].$(op)
```

### 调用写入
```mcfunction
data modify storage ns:io op set value "data.inv set from entity @s Inventory"
function ns:data/modify
```

### 导出宏
`data/<namespace>/function/data/export/macro.mcfunction`
```mcfunction
$data modify $(op) from storage ns:io data[{id:$(id)}].$(path)
```

### 调用导出
```mcfunction
data modify storage ns:io op set value "storage ns:io output set"
data modify storage ns:io path set value "data.inv"
function ns:data/export
```

## 实战：背包自动同步

### 进度监听
`data/<namespace>/advancement/inv_changed.json`
```json
{
  "criteria": {
    "a": { "trigger": "minecraft:inventory_changed" }
  },
  "requirements": [["a"]],
  "rewards": { "function": "ns:inv_sync" }
}
```

### 同步函数
```mcfunction
data modify storage ns:io op set value "data.inventory set from entity @s Inventory"
function ns:data/modify
advancement revoke @s only ns:inv_changed
```

## 宏易错点
1. `$` 必须在行首：`$data ...` 不是 `data $...`
2. `function ... with storage ...` 传的是整个花括号：`with storage ns:io`（不是 `ns:io id`）
3. `$()` 里只能写键名，不能写路径：`$(id)` 正确，`$(data.id)` 错误
