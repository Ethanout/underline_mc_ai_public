# 如何制作自定义实体外观

## 核心挑战

Minecraft 原版数据包无法直接创建新实体类型或修改现有实体的模型/纹理。所有"自定义实体外观"的方案本质上都是**利用现有实体的视觉特性进行伪装**，通过组合不同的实体、装备、属性修改器来模拟出全新的外观。

## 方案一：装备 + 盔甲架（最灵活，1.13+）

### 原理

盔甲架（Armor Stand）可以装备物品，且可以调整姿态（Pose NBT）。通过给盔甲架装备自定义头颅（Player Head）、盔甲、手持物品，并利用 `Invisible` 标签隐藏盔甲架本身，只显示其装备，可以组合出各种外观。

### 完整实现

#### 1. 生成自定义实体

`data/<namespace>/function/summon_custom_entity.mcfunction`
```mcfunction
# 生成一个不可见的盔甲架作为基础
summon minecraft:armor_stand ~ ~ ~ {Invisible:1b,NoGravity:1b,Marker:0b,Small:0b,DisabledSlots:0,ShowArms:1b,Pose:{Body:[0f,0f,0f],Head:[0f,0f,0f],LeftArm:[0f,0f,0f],RightArm:[0f,0f,0f],LeftLeg:[0f,0f,0f],RightLeg:[0f,0f,0f]}}

# 给盔甲架添加标签以便识别
tag @e[type=minecraft:armor_stand,dx=0,dy=0,dz=0,sort=nearest,limit=1] add custom_entity

# 设置自定义名称（显示在头顶）
data merge entity @e[tag=custom_entity,limit=1] {CustomName:'{"text":"Custom Entity","color":"gold"}',CustomNameVisible:1b}
```

#### 2. 设置装备（外观）

`data/<namespace>/function/set_appearance.mcfunction`
```mcfunction
# 设置头盔（自定义头颅）
# 需要先准备一个自定义头颅物品（通过 give 或 loot table）
give @p minecraft:player_head{SkullOwner:{Id:[I;-12345678,12345678,-12345678,12345678],Properties:{textures:[{Value:"eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6Ly90ZXh0dXJlcy5taW5lY3JhZnQubmV0L3RleHR1cmUv..."}]}}} 1

# 将头颅装备到盔甲架头部
item replace entity @e[tag=custom_entity,limit=1] armor.head with minecraft:player_head{SkullOwner:{Id:[I;-12345678,12345678,-12345678,12345678],Properties:{textures:[{Value:"eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6Ly90ZXh0dXJlcy5taW5lY3JhZnQubmV0L3RleHR1cmUv..."}]}}}

# 设置身体（胸甲）
item replace entity @e[tag=custom_entity,limit=1] armor.chest with minecraft:leather_chestplate{display:{color:16711680}}  # 红色

# 设置腿部（护腿）
item replace entity @e[tag=custom_entity,limit=1] armor.legs with minecraft:leather_leggings{display:{color:65280}}  # 绿色

# 设置脚部（靴子）
item replace entity @e[tag=custom_entity,limit=1] armor.feet with minecraft:leather_boots{display:{color:255}}  # 蓝色

# 设置主手物品
item replace entity @e[tag=custom_entity,limit=1] weapon.mainhand with minecraft:diamond_sword

# 设置副手物品
item replace entity @e[tag=custom_entity,limit=1] weapon.offhand with minecraft:shield
```

#### 3. 调整姿态

`data/<namespace>/function/set_pose.mcfunction`
```mcfunction
# 让盔甲架举起右手（攻击姿态）
data merge entity @e[tag=custom_entity,limit=1] {Pose:{RightArm:[0f,0f,-90f]}}

# 让盔甲架低头
data merge entity @e[tag=custom_entity,limit=1] {Pose:{Head:[30f,0f,0f]}}
```

### 陷阱与注意事项

1. **盔甲架碰撞箱**：即使 `Invisible:1b`，盔甲架仍然有碰撞箱。如果不需要碰撞，设置 `Marker:1b`，但这样会无法显示装备（Marker 模式下装备不可见）。折中方案：使用 `NoGravity:1b` 并保持 `Marker:0b`，然后通过 `teleport` 控制位置。

2. **装备显示限制**：只有 `ShowArms:1b` 时才会显示手持物品。`Small:1b` 会使盔甲架变小，但装备也会相应缩小。

3. **自定义头颅纹理**：需要预先通过第三方工具（如 Minecraft-Heads.com）获取纹理值（Value），或者使用 `/data` 命令从已有头颅复制。

4. **性能开销**：每个自定义实体都是一个完整的盔甲架实体，大量使用（>50个）可能影响性能。开销中等。

## 方案二：展示实体（Display Entity，1.19.4+）

### 原理

1.19.4 引入了三种展示实体：`block_display`、`item_display`、`text_display`。它们可以渲染方块、物品或文本，并支持变换（transformation）、亮度（brightness）、视图范围（view_range）等属性。通过组合多个展示实体，可以构建复杂外观。

### 完整实现

#### 1. 创建基础展示实体

`data/<namespace>/function/summon_display.mcfunction`
```mcfunction
# 创建一个物品展示实体（显示一个自定义头颅）
summon minecraft:item_display ~ ~ ~ {item:{id:"minecraft:player_head",count:1,components:{"minecraft:profile":{name:"CustomHead",id:[I;-12345678,12345678,-12345678,12345678],properties:[{name:"textures",value:"eyJ0ZXh0dXJlcyI6eyJTS0lOIjp7InVybCI6Imh0dHA6Ly90ZXh0dXJlcy5taW5lY3JhZnQubmV0L3RleHR1cmUv..."}]}}},transformation:{left_rotation:[0f,0f,0f,1f],right_rotation:[0f,0f,0f,1f],translation:[0f,0f,0f],scale:[2f,2f,2f]},brightness:{block:15,sky:15},view_range:64f}

# 添加标签
tag @e[type=minecraft:item_display,dx=0,dy=0,dz=0,sort=nearest,limit=1] add custom_display
```

#### 2. 组合多个展示实体

`data/<namespace>/function/create_composite.mcfunction`
```mcfunction
# 身体部分（使用 block_display 显示一个方块）
summon minecraft:block_display ~ ~1 ~ {block_state:{Name:"minecraft:stone"},transformation:{left_rotation:[0f,0f,0f,1f],right_rotation:[0f,0f,0f,1f],translation:[0f,0f,0f],scale:[1f,2f,1f]}}
tag @e[type=minecraft:block_display,dx=0,dy=0,dz=0,sort=nearest,limit=1] add body_part

# 头部（使用 item_display 显示头颅）
summon minecraft:item_display ~ ~2.5 ~ {item:{id:"minecraft:player_head",count:1,components:{"minecraft:profile":{name:"Head"}}},transformation:{left_rotation:[0f,0f,0f,1f],right_rotation:[0f,0f,0f,1f],translation:[0f,0f,0f],scale:[1.5f,1.5f,1.5f]}}
tag @e[type=minecraft:item_display,dx=0,dy=0,dz=0,sort=nearest,limit=1] add head_part

# 手臂（使用 item_display 显示剑）
summon minecraft:item_display ~1.5 ~1.5 ~ {item:{id:"minecraft:diamond_sword",count:1},transformation:{left_rotation:[0f,0f,0f,1f],right_rotation:[0f,0f,0f,1f],translation:[0f,0f,0f],scale:[1f,1f,1f]}}
tag @e[type=minecraft:item_display,dx=0,dy=0,dz=0,sort=nearest,limit=1] add arm_part
```

#### 3. 控制展示实体

`data/<namespace>/function/control_display.mcfunction`
```mcfunction
# 移动所有部件（通过父实体或单独 teleport）
# 方法1：使用父实体（需要额外创建一个标记实体作为父节点）
summon minecraft:marker ~ ~ ~ {Tags:["parent_marker"]}
# 然后让所有展示实体以 marker 为参考系移动
execute as @e[tag=body_part] at @e[tag=parent_marker,limit=1] run tp @s ~ ~ ~
execute as @e[tag=head_part] at @e[tag=parent_marker,limit=1] run tp @s ~ ~2.5 ~
execute as @e[tag=arm_part] at @e[tag=parent_marker,limit=1] run tp @s ~1.5 ~1.5 ~

# 方法2：直接 teleport 所有部件（简单但繁琐）
tp @e[tag=body_part] ~ ~1 ~
tp @e[tag=head_part] ~ ~2.5 ~
tp @e[tag=arm_part] ~1.5 ~1.5 ~
```

### 陷阱与注意事项

1. **版本要求**：展示实体仅在 1.19.4+ 可用。1.20.5+ 中物品组件格式有变化（使用 `components` 字段而非 `tag`）。

2. **组合复杂度**：每个部件都是独立实体，需要单独控制位置和旋转。大量部件会显著增加实体数量，影响性能。

3. **光照问题**：展示实体默认不受方块光照影响，需要手动设置 `brightness` 字段。

4. **交互性差**：展示实体无法被玩家攻击、交互，只能作为纯视觉效果。

5. **性能开销**：每个展示实体开销略低于盔甲架，但组合多个部件后总开销可能更高。开销中等。

## 方案三：隐形生物 + 装备（1.13+，最简单）

### 原理

让一个生物（如僵尸、骷髅）隐形，然后通过装备物品来显示外观。这种方法利用了生物的原生 AI（移动、攻击、受伤动画），适合制作有行为逻辑的自定义实体。

### 完整实现

#### 1. 生成隐形生物

`data/<namespace>/function/summon_invisible_mob.mcfunction`
```mcfunction
# 生成一个隐形的僵尸
summon minecraft:zombie ~ ~ ~ {Invisible:1b,NoAI:1b,Silent:1b,PersistenceRequired:1b,CanPickUpLoot:0b,ArmorItems:[{id:"minecraft:leather_boots",count:1,components:{"minecraft:dyed_color":{rgb:255}}},{id:"minecraft:leather_leggings",count:1,components:{"minecraft:dyed_color":{rgb:65280}}},{id:"minecraft:leather_chestplate",count:1,components:{"minecraft:dyed_color":{rgb:16711680}}},{id:"minecraft:player_head",count:1,components:{"minecraft:profile":{name:"CustomHead"}}}],HandItems:[{id:"minecraft:diamond_sword",count:1},{id:"minecraft:shield",count:1}]}

# 添加标签
tag @e[type=minecraft:zombie,dx=0,dy=0,dz=0,sort=nearest,limit=1] add custom_mob
```

#### 2. 控制行为

`data/<namespace>/function/control_mob.mcfunction`
```mcfunction
# 让自定义实体跟随玩家
execute as @e[tag=custom_mob] at @s run tp @s ^ ^ ^0.5 facing entity @p

# 或者使用原版 AI（如果 NoAI:0b）
# 设置目标
data merge entity @e[tag=custom_mob,limit=1] {AttackTime:0,HurtTime:0}
```

### 陷阱与注意事项

1. **生物模型限制**：不同生物有不同的模型（僵尸 vs 骷髅 vs 蜘蛛），选择生物决定了基础骨架。僵尸模型最接近人类。

2. **隐形效果**：`Invisible:1b` 会使生物本身不可见，但装备仍然显示。注意：在 1.20.5+ 中，装备格式改为 `components` 字段。

3. **AI 冲突**：如果启用 AI（`NoAI:0b`），生物会执行原版行为（如僵尸攻击村民），可能不符合预期。建议设置 `NoAI:1b` 并手动控制。

4. **受伤动画**：即使隐形，生物被攻击时仍会显示红色闪烁和击退效果。可以通过 `Invulnerable:1b` 避免，但这样也无法被杀死。

5. **性能开销**：生物实体开销高于盔甲架，但低于多个展示实体组合。开销中等偏高。

## 方案对比

| 方案 | 最低版本 | 外观灵活性 | 交互性 | 性能开销 | 适用场景 |
|------|----------|------------|--------|----------|----------|
| 盔甲架装备 | 1.13 | 高（可自定义姿态） | 低（无原生交互） | 中等 | 静态NPC、装饰性实体 |
| 展示实体 | 1.19.4 | 极高（可组合任意方块/物品） | 极低（无交互） | 中等 | 复杂视觉效果、UI元素 |
| 隐形生物 | 1.13 | 中（受生物模型限制） | 高（可攻击、移动） | 中高 | 有行为逻辑的敌人、宠物 |

## 总结

- **需要交互性**（可攻击、可移动）：选择方案三（隐形生物）
- **需要复杂外观**（自定义姿态、多部件）：选择方案一（盔甲架）
- **需要纯视觉效果**（无交互、高自由度）：选择方案二（展示实体）
- **版本限制**：如果目标版本低于 1.19.4，只能使用方案一或三
