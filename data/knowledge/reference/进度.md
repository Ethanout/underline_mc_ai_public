# 进度

位置：`data/<namespace>/advancement/<path>.json`

## 根结构
```json
{
  "criteria": { ... },
  "display": { ... },
  "parent": "ns:parent",
  "requirements": [["criterion1"], ["criterion2"]],
  "rewards": { ... },
  "sends_telemetry_event": false
}
```
- `criteria`（必填）：触发器字典
- `display`：显示设置（逻辑型进度可省略）
- `parent`：父进度（根进度省略）
- `requirements`：OR-of-ANDs 逻辑（默认全部完成）
- `rewards`：经验、函数、战利品表、配方
- `sends_telemetry_event`：仅 `minecraft` 命名空间有效

## 显示设置
```json
{
  "display": {
    "title": { "text": "Title" },
    "description": { "text": "Desc" },
    "icon": { "id": "minecraft:diamond", "count": 1 },
    "background": "minecraft:textures/gui/advancements/backgrounds/stone.png",
    "frame": "task",
    "show_toast": true,
    "announce_to_chat": true,
    "hidden": false
  }
}
```
框架：`task`（方角）、`goal`（圆角）、`challenge`（尖角）
背景仅根进度有效。

### 可见规则
- 根进度或有可见父进度的 `display` + 非 `hidden` → 可见
- `hidden` 进度完成后才显示

## 触发器类型（57+ 种）

### 背包与物品
`inventory_changed` `item_durability_changed` `consume_item` `filled_bucket` `using_item` `enchanted_item` `recipe_crafted` `recipe_unlocked`

### 方块
`placed_block` `enter_block` `any_block_use` `default_block_use` `item_used_on_block` `bee_nest_destroyed` `slide_down_block`

### 战斗与伤害
`player_hurt_entity` `player_killed_entity` `entity_hurt_player` `entity_killed_player` `shot_crossbow` `target_hit` `killed_by_arrow` `spear_mobs`

### 移动与维度
`changed_dimension` `fall_from_height` `fall_after_explosion` `levitation` `nether_travel` `started_riding` `location`（每20tick）

### 状态效果
`effects_changed` `brewed_potion` `used_totem` `cured_zombie_villager` `construct_beacon`

### 实体互动
`bred_animals` `tame_animal` `summoned_entity` `player_interacted_with_entity` `villager_trade` `thrown_item_picked_up_by_player` `fishing_rod_hooked` `allay_drop_item_on_block` `player_sheared_equipment` (1.21.6)

### 特殊
`impossible`（只能 `/advancement grant`）`tick`（每tick）`slept_in_bed` `lightning_strike` `voluntary_exile` `hero_of_the_village` `kill_mob_near_sculk_catalyst`

## 多数触发器共有条件
```json
{
  "player": {
    "location": { "biome": "minecraft:desert" }
  }
}
```

## 需求逻辑
```json
"requirements": [["a","b"]]   // a AND b
"requirements": [["a"],["b"]] // a OR b
```

## 奖励
```json
"rewards": {
  "experience": 100,
  "function": "ns:reward",
  "loot": ["ns:loot_table"],
  "recipes": ["ns:recipe"]
}
```
- `function` 以玩家身份执行
- `loot` 用 `this_entity`=玩家上下文给予

## 进度作为事件监听器
隐藏进度（无 `display`）触发后立刻运行 `rewards.function`：
```json
{
  "criteria": {
    "on_event": {
      "trigger": "minecraft:tick"
    }
  },
  "rewards": {
    "function": "ns:handler"
  }
}
```
重复触发需在手处理函数末尾 `advancement revoke @s only <id>`。
