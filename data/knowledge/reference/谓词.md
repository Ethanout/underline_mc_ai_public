# 谓词

位置：`data/<namespace>/predicate/<path>.json`

## 用法
- 选择器：`@a[predicate=ns:path]`
- 命令：`execute if predicate ns:path`
- 内联：`execute if predicate {condition:"...",predicate:{...}}`
- 战利品表/进度：在 `conditions` 中

## 文件格式
单条件对象形式：
```json
{
  "condition": "minecraft:entity_properties",
  "entity": "this",
  "predicate": { ... }
}
```
数组形式（多条件 = AND）：
```json
[
  { "condition": "minecraft:location_check", ... },
  { "condition": "minecraft:weather_check", ... }
]
```

## 逻辑谓词
| 类型 | 作用 |
|------|------|
| `all_of` | AND（`terms` 数组） |
| `any_of` | OR（`terms` 数组） |
| `inverted` | NOT（`term` 单个） |
| `reference` | 引用其他文件（`name`） |

## 实体谓词

### entity_properties
```
{
  "condition": "minecraft:entity_properties",
  "entity": "this",
  "predicate": {
    "type": "minecraft:zombie",
    "location": { "biome": "minecraft:plains", "dimension": "overworld" },
    "flags": { "is_on_fire": true, "is_sneaking": false },
    "equipment": { "mainhand": { "items": ["diamond_sword"] } },
    "effects": { "minecraft:speed": { "amplifier": {"min": 0} } },
    "nbt": "{IsBaby:1b}",
    "type_specific": {
      "type": "player",
      "gamemode": "creative",
      "advancements": { "story/mine_diamond": true },
      "input": { "forward": true, "sneak": true }  // 1.21.2+
    }
  }
}
```

#### equipment 谓词（1.21.5+ 简化格式）

1.21.5+ 物品组件简化，魔咒组件 `levels` 字段已内联到顶层：

```json
"minecraft:equipment": {
  "mainhand": {
    "items": "minecraft:carrot_on_a_stick",
    "count": 1,
    "components": {
      "minecraft:custom_data": { "id": "pvp:dash" }
    },
    "predicates": {
      "minecraft:enchantments": [
        { "enchantment": "minecraft:sharpness", "levels": 5 }
      ]
    }
  }
}
```

槽位：`mainhand` / `offhand` / `head` / `chest` / `legs` / `feet` / `saddle`

`entity` 取值：`this`, `attacker`, `direct_attacker`, `attacking_player`, `target_entity`, `interacting_entity`

## 数据组件谓词 (Data Component Predicates, 1.21.5+)
原名 "物品子谓词 (Item sub-predicates)"。用于检测物品的组件。可用于 `match_tool`、物品修饰器条件，以及 **1.21.5+ 起直接用于实体和方块谓词的 `items` 字段**。

### 核心子谓词
- `custom_data`: 检测 NBT 数据。支持 JSON 对象或 SNBT 字符串。
- `enchantments`: 检测附魔。在物品组件中，`levels` 字段已内联。但在谓词匹配中，仍使用 `enchantments` 数组。
- `attribute_modifiers`: 检测属性。字段已由 `name`/`uuid` 变更为 `id` (1.21+)。
- `container`: 检测容器内容。
- `bundle_contents`: 检测收纳袋内容。
- `damage`: 检测耐久损失。

## 物品谓词

### match_tool
```json
{
  "condition": "minecraft:match_tool",
  "predicate": {
    "items": "minecraft:diamond_pickaxe",
    "predicates": {
      "minecraft:enchantments": [
        { "enchantments": "minecraft:silk_touch", "levels": {"min": 1} }
      ]
    }
  }
}
```
需要上下文 `tool`。

## 伤害与战斗谓词

### damage_source_properties
```json
{
  "condition": "minecraft:damage_source_properties",
  "predicate": {
    "tags": [{ "id": "minecraft:is_fire", "expected": true }],
    "is_direct": true
  }
}
```
需要 `origin` 和 `damage_source`。

### killed_by_player / survives_explosion
简单布尔判断。

## 随机谓词

| 类型 | 用途 |
|------|------|
| `random_chance` | 固定概率 `chance` |
| `random_chance_with_enchanted_bonus` | 附魔影响的概率 |
| `table_bonus` | 按附魔等级查表 |

## 环境谓词

| 类型 | 用途 |
|------|------|
| `weather_check` | 天气检测 |
| `time_check` | 时刻检测（`period` 可模运算） |
| `environment_attribute_check` (26.1) | 环境属性检测 |
| `enchantment_active_check` | 附魔是否激活 |
