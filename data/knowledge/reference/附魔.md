# 附魔

位置：`data/<namespace>/enchantment/<path>.json`

> 附魔定义**不可热重载**，需重启服务器。

## 根结构
```json
{
  "description": { "text": "Life Steal", "color": "red" },
  "anvil_cost": 4,
  "max_level": 3,
  "weight": 5,
  "min_cost": { "base": 10, "per_level_above_first": 10 },
  "max_cost": { "base": 50, "per_level_above_first": 10 },
  "supported_items": "#minecraft:enchantable/sword",
  "primary_items": "#minecraft:enchantable/sword",
  "slots": ["mainhand"],
  "exclusive_set": "#minecraft:exclusive_set/damage",
  "effects": { ... }
}
```

### 关键字段
- `anvil_cost`：铁砧经验倍数
- `weight`：随机附魔权重 1~1024
- `min_cost`/`max_cost`：附魔等级计算公式
- `supported_items`：可接受物品的 ID/标签
- `primary_items`：附魔台可出（`supported_items` 子集）
- `slots`：生效槽位（`mainhand`/`offhand`/`head`/`chest`/`legs`/`feet`）
- `exclusive_set`：互斥附魔

### 等级计算
对等级 n，附魔等级范围：
```
min_cost.base + per_level * (n-1)  ~  max_cost.base + per_level * (n-1)
```

## 效果组件

### 数值效果（Value Effects）
`add` / `multiply` / `set` / `remove_binomial` / `exponential` / `all_of`

### 级别依赖值
`linear`（`base + per_level * (level-1)`）、`clamped`、`fraction`、`levels_squared`、`lookup`

### 数值效果注册表
| 组件 | 修改目标 |
|------|----------|
| `crossbow_charge_time` | 弩装填时间 |
| `trident_spin_attack_strength` | 激流速度 |
| `ammo_use` | 弹药消耗 |
| `block_experience` | 方块经验 |
| `item_damage` | 耐久消耗 |
| `projectile_piercing` | 穿透数 |
| `repair_with_xp` | 经验修补 |
| `armor_effectiveness` | 护甲减伤比 |
| `damage` | 攻击伤害 |
| `damage_protection` | 保护系数 |
| `knockback` | 击退 |
| `mob_experience` | 生物经验 |
| `projectile_count` | 多重射击箭数 |
| `projectile_spread` | 多重射击散布 |
| `trident_return_acceleration` | 忠诚速度 |

### 实体效果（Entity Effects）
| 类型 | 作用 |
|------|------|
| `apply_mob_effect` | 施加状态效果 |
| `damage_entity` | 造成伤害 |
| `explode` | 爆炸 |
| `ignite` | 点燃 |
| `apply_impulse` | 施加冲量 |
| `change_item_damage` | 改变耐久 |
| `play_sound` | 播放声音 |
| `spawn_particles` | 生成粒子 |
| `summon_entity` | 召唤实体 |
| `replace_block` | 替换方块 |
| `replace_disk` | 圆盘替换 |
| `set_block_properties` | 设置方块属性 |
| `run_function` | 运行函数 |

### 实体效果触发时机
`tick`（每tick）、`post_piercing_attack`（穿刺攻击后）、`projectile_spawned`（射弹生成）、`hit_block`（击中方块）、`post_attack`（攻击后，需指定 `enchanted`/`affected`）、`location_changed`（位置变化）

### 属性效果
```json
{
  "type": "minecraft:add",
  "attribute": "minecraft:generic.max_health",
  "operation": "add_value",
  "amount": { "type": "minecraft:linear", "base": 2.0, "per_level_above_first": 2.0 },
  "id": "ns:id",
  "slot": "any"
}
```

### 其他组件
- `damage_immunity`：伤害免疫
- `crossbow_charging_sounds`：弩装填音效
- `trident_sound`：三叉戟音效
- `prevent_armor_change`：阻止卸甲
- `prevent_equipment_drop`：阻止掉落
