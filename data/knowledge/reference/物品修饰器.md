# 物品修饰器

位置：`data/<namespace>/item_modifier/<name>.json`

## 使用
```mcfunction
item modify entity @s weapon.mainhand ns:modifier
item replace block ~ ~ ~ container.0 from entity @s weapon.mainhand ns:modifier
```

## 格式
单条：
```json
{ "function": "minecraft:set_count", "count": 1 }
```
多条：
```json
[
  { "function": "minecraft:set_count", "count": 1 },
  { "function": "minecraft:set_name", "name": {"text":"My Item"} }
]
```
带条件：
```json
{
  "conditions": [{ "condition": "random_chance", "chance": 0.5 }],
  "function": "minecraft:set_count", "count": 64
}
```

## 类型大全

### 数量
`set_count` `limit_count` `enchanted_count_increase`

### 附魔
`enchant_randomly` `enchant_with_levels` `set_enchantments`

### 名称与描述
`set_name` `set_lore` `copy_name`（来源：`this`/`attacker`/`block_entity` 等）

### 组件
`set_components`（加 `!` 前缀移除）、`copy_components`、`set_custom_data`（合并到 `custom_data`）、`copy_custom_data`

### 耐久
`set_damage`

### 容器内容
`set_contents`（`container`/`bundle_contents`/`charged_projectiles`）、`modify_contents`

### 书
`set_book_cover` `set_writable_book_pages` `set_written_book_pages`

### 烟花
`set_fireworks` `set_firework_explosion`

### 特殊物品
`set_potion` `set_random_potion` `set_ominous_bottle_amplifier` `set_stew_effect` `set_instrument` `exploration_map` `fill_player_head`

### 属性
`set_attributes`（`add_value`/`add_multiplied_base`/`add_multiplied_total`）

### 旗帜
`set_banner_pattern`

### 模型数据
`set_custom_model_data`（`floats`/`flags`/`strings`/`colors`，模式：`replace_all`/`append`/`insert`）

### 工具
`apply_bonus`（`uniform_bonus_count`/`ore_drops`/`binomial_with_bonus_count`）、`copy_state`、`set_item`、`set_loot_table`、`furnace_smelt`、`explosion_decay`、`discard`、`toggle_tooltips`

### 流程控制
`filtered`（条件分支）、`sequence`（顺序执行）、`reference`（引用其他文件）
