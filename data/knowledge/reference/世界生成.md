# 世界生成

位置：`data/<namespace>/worldgen/`

> 世界生成定义**不可热重载**，需重进世界。

## 子目录
```
worldgen/
├── biome/                          生物群系
├── configured_carver/              洞穴/峡谷
├── configured_feature/             配置特征
├── density_function/               密度函数
├── flat_level_generator_preset/    超平坦预设
├── multi_noise_biome_source_parameter_list/ 多噪声生物群系分布
├── noise/                          噪声
├── noise_settings/                 噪声设置（地形形状）
├── placed_feature/                 放置特征
├── processor_list/                 结构处理器
├── structure/                      结构
├── structure_set/                  结构集
├── template_pool/                  拼图模板池
└── world_preset/                   世界预设
```

## 维度定义
`data/<namespace>/dimension/<name>.json`
```json
{
  "type": "minecraft:overworld",
  "generator": {
    "type": "minecraft:noise",
    "settings": "minecraft:overworld",
    "biome_source": { "type": "minecraft:multi_noise", "preset": "minecraft:overworld" }
  }
}
```
生成器：`noise`, `flat`, `debug`

### 维度类型
`data/<namespace>/dimension_type/<name>.json`
关键字段：`ultrawarm` `natural` `coordinate_scale` `has_skylight` `has_ceiling` `ambient_light` `monster_spawn_light_level` `logical_height` `min_y` `height` `infiniburn` `effects` `cloud_height`(26.1)

## 生物群系
`worldgen/biome/<name>.json`
字段：`temperature` `downfall` `has_precipitation` `effects`（颜色、声音、粒子）`carvers` `features` `spawners`
features 数组按阶段索引：0=原始生成 → 1=湖泊 → ... → 10=地表修改

## 配置特征
`worldgen/configured_feature/<name>.json`
类型：`ore` `tree` `flower` `lake` `spring` `random_patch` `geode` `fossil` `huge_fungus` 等

## 放置特征
`worldgen/placed_feature/<name>.json`
```json
{
  "feature": "minecraft:ore_iron",
  "placement": [
    { "type": "count", "count": 20 },
    { "type": "in_square" },
    { "type": "height_range", "height": { "type": "trapezoid", "min_inclusive": { "absolute": -24 }, "max_inclusive": { "absolute": 56 } } }
  ]
}
```

## 结构
### Jigsaw 结构
`worldgen/structure/<name>.json` — `type: jigsaw` + `start_pool` + `size` + `biomes`

### 模板池
`worldgen/template_pool/<name>.json` — `fallback` + `elements[]`（含 `weight` + `element_type` + `location` + `processors`）

### 处理器
`worldgen/processor_list/<name>.json` — 规则处理器（`rule` `block_rot` `block_age` `protected_blocks` 等）

### 结构集
`worldgen/structure_set/<name>.json` — `structures[]` + `placement`（`random_spread`/`concentric_rings`）
