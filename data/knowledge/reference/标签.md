# 标签

位置：`data/<namespace>/tags/<registry>/<name>.json`

## 格式
```json
{
  "replace": false,
  "values": [
    "minecraft:oak_log",
    "#minecraft:logs_that_burn",
    { "id": "optional:item", "required": false }
  ]
}
```
- `replace`：`false`=合并，`true`=覆盖低优先级
- `#` 前缀：引用另一个标签
- `required: false`：忽略缺失条目

## 注册表类型
| 路径 | 用途 |
|------|------|
| `tags/block` | 方块 |
| `tags/item` | 物品 |
| `tags/entity_type` | 实体类型 |
| `tags/fluid` | 流体 |
| `tags/function` | 函数（不是注册表，但有特殊行为） |
| `tags/game_event` | 游戏事件 |
| `tags/damage_type` | 伤害类型 |
| `tags/enchantment` | 附魔 |
| `tags/biome` | 生物群系 |
| `tags/structure` | 结构 |
| `tags/painting_variant` | 画变种 |
| `tags/instrument` | 乐器 |
| `tags/dialog` | 对话框 |
| `tags/timeline` | 时间线 |
| `tags/worldgen/biome` | 世界生成生物群系 |
| `tags/worldgen/configured_feature` | 配置特征 |
| `tags/worldgen/structure` | 结构 |
| `tags/worldgen/world_preset` | 世界预设 |
| `tags/flat_level_generator_preset` | 超平坦预设 |
| `tags/point_of_interest_type` | 兴趣点类型 |

## 特殊函数标签
- `#minecraft:load`：加载时执行（无玩家在线，不可用 tellraw）
- `#minecraft:tick`：每 tick 执行

## 使用
```mcfunction
execute if block ~ ~-1 ~ #minecraft:dirt run ...
execute if entity @e[type=#minecraft:skeletons] ...
function #mypack:daily_tasks
```
配方/战利品表/附魔/谓词/世界生成中同样可用 `#tag`。
