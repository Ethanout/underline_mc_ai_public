# 其他注册表与实验性功能

## 其他注册表

| 注册表 | 路径 | 用途 |
|--------|------|------|
| 伤害类型 | `damage_type/` | 自定义伤害类型和标签 |
| 画变种 | `painting_variant/` | 挂在画框中的画 |
| 唱片机曲目 | `jukebox_song/` | 唱片机播放的曲目 |
| 盔甲纹饰材料 | `trim_material/` | 纹饰颜色/材质 |
| 盔甲纹饰图案 | `trim_pattern/` | 纹饰形状 |
| 对话 | `dialog/` | 暂停菜单/G菜单对话框 |
| 时间线 | `timeline/` | 时间线事件 |
| 交易组 | `trade_set/` | 村民交易（26.1 数据驱动） |
| 村民交易 | `villager_trade/` | 单个村民交易条目 |
| 试炼刷怪笼 | `trial_spawner/` | 试炼刷怪笼配置 |
| 世界时钟 | `world_clock/` | 世界周期时钟 |
| 生物变种 | `cat_variant/` `wolf_variant/` `frog_variant/` `pig_variant/` `chicken_variant/` `cow_variant/` `wolf_sound_variant/` | 生物纹理变种 |
| 乐器 | `instrument/` | 山羊角音效 |
| 聊天类型 | `chat_type/` | 聊天格式 |
| 旗帜图案 | `banner_pattern/` | 旗帜图案 |
| 附魔提供者 | `enchantment_provider/` | 附魔来源表 |
| 游戏测试 | 实验性 | 自动化测试 |

## 实验性功能

需要 `features.enabled` 才能使用的功能：

| 功能 ID | 启用内容 |
|---------|----------|
| `minecraft:update_1_21` | 试炼刷怪笼、锻造模板、装饰罐等 1.21 内容 |
| `minecraft:update_1_21_4` | 后续更新内容 |

注意：
- 有 `features` 字段的数据包只能在创建世界时加入
- 旧世界要启用需手动修改 `level.dat`
