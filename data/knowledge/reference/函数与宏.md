# 函数与宏

## 基本定义
`.mcfunction` 文件，每行一个命令（**不带前导 `/`**）。
```
# 注释
say Hello
give @s diamond
```
位置：`data/<namespace>/function/<path>.mcfunction`
ID：`<namespace>:<path>`

## 续行
行末 `\` 可续行到下一行。

## 执行上下文
函数继承调用者的执行实体、位置、旋转、维度、锚点。

### 命令限制
- 所有命令（含子函数）在**单 tick** 内执行
- 受 `maxCommandChainLength` 限制（默认 65536）
- 宏展开后最大 2,000,000 字符

## 调用方式
```
function ns:path         — 直接调用
function #ns:tag         — 调用标签中所有函数
execute if function ns:path  — 条件执行（检测返回值）
```

### 特殊函数标签
```json
// data/minecraft/tags/function/load.json
{ "values": ["mypack:init"] }
```
```json
// data/minecraft/tags/function/tick.json
{ "values": ["mypack:tick"] }
```
- `#minecraft:load`：世界加载/服务器启动/`/reload` 时执行，**此时无玩家在线**
- `#minecraft:tick`：每 tick 开始时执行

### 其他调用方式
- 进度奖励（`rewards.function`）
- `schedule function` 延迟调用
- 附魔效果 `run_function`

## 宏（1.20.2+）
宏行以 `$` 开头，运行时替换 `$(key)` 占位符：
```mcfunction
$give @s $(item) $(count)
$say Hello $(name)!
```
键名：`a-z`, `A-Z`, `0-9`, `_`

### 调用宏
```
function ns:macro {item:"minecraft:diamond",count:5}
function ns:macro with entity @s SelectedItem
function ns:macro with storage ns:data path
```

### 值转换
- 数字：去类型后缀
- 字符串：去引号
- List/Compound：转 SNBT

### 性能
- 非宏行：加载时解析一次
- 宏行：每次调用时解析（重复参数会缓存）

## 返回值（/return）
```
return <value>     — success=true, result=<value>
return fail        — success=false
return run <cmd>   — 运行命令并用其结果
```

`execute if function` 检测返回非零值。`execute store ... run function` 存储函数返回值。

## 递归
函数可以调用自身。注意终止条件，否则 `maxCommandChainLength` 会截断。

## 调度（/schedule）
```
schedule function ns:path <time> [append|replace]
schedule clear ns:path
```
时间单位：`1d`（天=24000t）、`1s`（秒=20t）、`1t`（tick）、或纯 tick 数。

## 执行顺序（单 tick 内）
世界边界 → 函数 → 实体 → 方块实体 → 玩家
维度顺序：主世界 → 下界 → 末地（串行）
