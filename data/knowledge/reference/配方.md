# 配方

位置：`data/<namespace>/recipe/<name>.json`

## 配方类型
| 类型 | 用途 |
|------|------|
| `crafting_shaped` | 有序合成 |
| `crafting_shapeless` | 无序合成 |
| `crafting_transmute` | 类型转换（保留组件） |
| `crafting_dye` (26.1) | 染色 |
| `crafting_imbue` (26.1) | 灌注（箭→药水箭） |
| `smelting` | 熔炉 |
| `blasting` | 高炉 |
| `smoking` | 烟熏炉 |
| `campfire_cooking` | 营火 |
| `stonecutting` | 切石机 |
| `smithing_transform` | 锻造升级 |
| `smithing_trim` | 盔甲纹饰 |

### 26.1 移除
`crafting_special_armordye` `crafting_special_mapcloning` `crafting_special_tippedarrow`（分别被 `crafting_dye`、`imbue` 替代）

## 有序合成
```json
{
  "type": "minecraft:crafting_shaped",
  "category": "equipment",
  "key": {
    "#": "minecraft:stick",
    "X": "#minecraft:planks"
  },
  "pattern": ["X", "#", "#"],
  "result": { "id": "minecraft:wooden_sword", "count": 1 }
}
```
- 模式：最多 3×3，空格为空位
- Key：单字符（非空格）
- 输入：物品ID、ID列表或 `#tag`
- 自动对称匹配

## 无序合成
```json
{
  "type": "minecraft:crafting_shapeless",
  "ingredients": ["minecraft:iron_ingot", "minecraft:flint"],
  "result": { "id": "minecraft:flint_and_steel", "count": 1 }
}
```
1~9 个材料。每个可以是物品ID `{}, [{},{}]` 或 `#tag`。

## 转换配方（Transmute）
```json
{
  "type": "minecraft:crafting_transmute",
  "input": "minecraft:glass_bottle",
  "material": "minecraft:honey_bottle",
  "material_count": { "min": 1, "max": 4 },
  "result": { "id": "minecraft:honey_bottle" }
}
```
保留输入物品的组件。

## 其他类型
| 字段 | 说明 |
|------|------|
| `crafting_dye` | `target`（可染物）+ `dye` → `result`，混色 |
| `crafting_imbue` | `input`（箭）+ `ingredient`（滞留药水）→ `result`（药水箭） |
| `smelting/blasting/...` | `ingredient` + `result` + `experience` + `cookingtime` |
| `stonecutting` | `ingredient` + `result` |
| `smithing_transform` | `template` + `base` + `addition` → `result` |
| `smithing_trim` | `template` + `base` + `addition` |

## 带组件的输出（26.1）
```json
"result": {
  "id": "minecraft:diamond_sword",
  "count": 1,
  "components": {
    "minecraft:enchantments": { "levels": { "sharpness": 5 } }
  }
}
```

## 输入格式
```json
{ "item": "minecraft:stick" }
{ "tag": "minecraft:planks" }
["minecraft:oak_planks", "minecraft:birch_planks"]
{ "item": "minecraft:stick", "count": 2 }
```
