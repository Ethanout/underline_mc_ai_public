# 命令总表

> 不包含 `/execute`（见 05_execute详解.md）。所有命令基于 26.1.2。

## 语法记号
- `literal` — 原样书写
- `<必选>` — 必须提供
- `[可选]` — 可选
- `(a|b)` — 必选其一

---

## 函数与流程
```
function <name>                      — 运行函数
function <name> <NBT>               — 运行宏函数
function <name> with (block|entity|storage) <src> [path]
return <value> | fail | run <cmd>   — 设置返回值
schedule function <fn> <time> [append|replace]
schedule clear <fn>                 — 清空计划
```
