# 战利品表

位置：`data/<namespace>/loot_table/<path>.json`

## 根结构
```json
{
  "type": "minecraft:generic",
  "random_sequence": "ns:seq",
  "functions": [],
  "pools": []
}
```
- `type`：定义上下文参数集（`generic`/`block`/`entity`/`chest`/`fishing`/`gift`）
- `random_sequence`：命名随机序列（确定性掉落）
- `functions`：对所有产出物品应用的修饰器
- `pools`：随机池列表

## 池（Pool）
```json
{
  "rolls": { "type": "minecraft:uniform", "min": 1, "max": 3 },
  "bonus_rolls": 0,
  "conditions": [],
  "functions": [],
  "entries": []
}
```

### 数值提供器
| 类型 | 说明 |
|------|------|
| `constant` | 固定值 |
| `uniform` | 均匀分布 |
| `binomial` | 二项分布 |
| `storage` | 从 storage 读取 |
| `score` | 从计分板读取 |

## 条目类型
| 类型 | 说明 |
|------|------|
| `item` | 单物品 |
| `loot_table` | 引用战利品表 |
| `tag` | 标签物品（`expand` 控制展开方式） |
| `dynamic` | 动态内容（`contents`/`sherds`） |
| `empty` | 空 |
| `alternatives` | 首个通过的 |
| `group` | 全部执行 |
| `sequence` | 直到失败 |
| `slots` | 从物品栏取 |

条目字段：`weight`（权重）、`quality`（运气修正）、`conditions`、`functions`

## 自定义战利品表赋值
```mcfunction
data merge block <pos> {LootTable: "ns:path", LootTableSeed: 12345L}
data merge entity @e[type=zombie,limit=1] {DeathLootTable: "ns:path"}
```
命令：`loot spawn|give|insert <target> loot|fish|kill|mine ...`

## 内置分类
