# 目标选择器

## 基本选择器
| 选择器 | 描述 |
|--------|------|
| `@e` | 所有实体（仅加载区块中） |
| `@s` | 当前执行实体 |
| `@a` | 所有玩家 |
| `@r` | 随机玩家 |
| `@p` | 最近玩家 |
| `@n` | 最近实体 |

## 参数
| 参数 | 示例 | 描述 |
|------|------|------|
| `type` | `@e[type=pig]` | 实体类型（可用标签 `#aquatic`） |
| `name` | `@e[name="Bob"]` | 名称过滤 |
| `distance` | `@e[distance=..10]` | 距离范围 |
| `nbt` | `@a[nbt={...}]` | NBT 过滤（**性能极差，勿用**） |
| `sort` | `@e[sort=nearest,limit=1]` | 排序：`arbitrary`/`nearest`/`furthest`/`random` |
| `limit` | `@e[limit=5]` | 数量限制 |
| `x/y/z` | `@e[x=10,y=64,z=0]` | 参考位置 |
| `dx/dy/dz` | `@e[dx=10,dy=5,dz=10]` | 长方体区域 |
| `tag` | `@a[tag=admin]` | 标签过滤 |
| `team` | `@a[team=red]` | 队伍过滤 |
| `scores` | `@e[scores={obj=10}]` | 分数过滤 |
| `predicate` | `@e[predicate=my:pred]` | 谓词过滤 |
| `gamemode` | `@a[gamemode=creative]` | 游戏模式 |
| `advancements` | `@a[advancements={id=true}]` | 进度过滤 |
| `level` | `@a[level=10]` | 经验等级 |
| `x_rotation` | `@a[x_rotation=0..90]` | 俯仰角 |
| `y_rotation` | `@a[y_rotation=-180..-90]` | 偏航角 |
| `hasitem` | `@a[hasitem={...}]` | 物品过滤 |

## 反转选择
```
@e[type=!player]
@e[tag=!ignore]
```

## 距离范围语法
```
distance=5       — 恰好 5
distance=..5     — ≤5
distance=5..     — ≥5
distance=5..10   — 5~10
```

## 长方体区域
`dx/dy/dz` 以 (x,y,z) 为起点向正方向延伸。实际区域比指定值大 1 格（最小 1×1×1）。
