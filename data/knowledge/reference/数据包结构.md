# 数据包结构

## pack.mcmeta

### 现代格式（26.1.2，推荐）
```json
{
  "pack": {
    "description": "Example Pack",
    "min_format": [101, 1],
    "max_format": [101, 1]
  }
}
```
字段：
- **description**（必填）：文本组件描述
- **min_format**（必填）：`[major, minor]` 最低兼容版本
- **max_format**（必填）：`[major, minor]` 最高兼容版本
- **pack_format**（旧）：单整数，为兼容保留
- **supported_formats**（旧）：整数范围，已弃用

### 版本格式选择规则

以数据包版本 81（1.21.8）为界，有三种格式写法：

**仅1.21.8及之前**（pack_format ≤ 81）：
```json
{
  "pack": {
    "pack_format": 61,
    "supported_formats": [48, 61]
  }
}
```

**仅1.21.8之后**（min_format > 81）：
```json
{
  "pack": {
    "min_format": [88, 0],
    "max_format": [101, 1]
  }
}
```

**同时兼容前后**（混合写法）：
```json
{
  "pack": {
    "pack_format": 101,
    "supported_formats": [48, 101],
    "min_format": 48,
    "max_format": [101, 1]
  }
}
```

### features（启用实验性内容）
```json
{
  "features": {
    "enabled": ["minecraft:update_1_21"]
  }
}
```
有 `features` 字段的包必须在创建世界时加入。

### filter（屏蔽低优先级包）
```json
{
  "filter": {
    "block": [
      { "namespace": "minecraft", "path": "advancement/*" }
    ]
  }
}
```
用正则匹配屏蔽来自低优先级数据包的文件。

### overlays（多版本分层）
```json
{
  "overlays": {
    "entries": [
      { "directory": "v1_21", "min_format": 48, "max_format": 70 }
    ]
  }
}
```
覆盖目录必须包含自己的 `data/` 和 `assets/`。

## 目录结构

```
<datapack>/
├── pack.mcmeta
├── pack.png
└── data/
    └── <namespace>/
        ├── function/           .mcfunction
        ├── advancement/        进度
        ├── banner_pattern/     旗帜图案
        ├── cat_variant/        猫变种
        ├── chat_type/          聊天类型
        ├── chicken_variant/    鸡变种
        ├── cow_variant/        牛变种
        ├── damage_type/        伤害类型
        ├── dialog/             对话框 (1.21.6)
        ├── dimension/          维度
        ├── dimension_type/     维度类型
        ├── enchantment/        附魔
        ├── enchantment_provider/ 附魔提供者
        ├── frog_variant/       青蛙变种
        ├── instrument/         山羊角
        ├── item_modifier/      物品修饰器
        ├── jukebox_song/       唱片机曲目
        ├── loot_table/         战利品表
        ├── painting_variant/   画变种
        ├── pig_variant/        猪变种
        ├── predicate/          谓词
        ├── recipe/             配方
        ├── tags/               标签
        │   ├── block/
        │   ├── item/
        │   ├── entity_type/
        │   ├── function/
        │   └── ...
        ├── timeline/           时间线 (1.21.11)
        ├── trade_set/          交易组
        ├── trial_spawner/      试炼刷怪笼
        ├── trim_material/      纹饰材料
        ├── trim_pattern/       纹饰图案
        ├── villager_trade/     村民交易
        ├── wolf_sound_variant/ 狼声音变种
        ├── wolf_variant/       狼变种
        ├── world_clock/        世界时钟 (26.1)
        └── worldgen/           世界生成
```

### 目录命名（26.1.2）
所有目录使用**单数**：`function`（非 functions）、`loot_table`（非 loot_tables）、`predicate`（非 predicates）、`tag` 子目录同理。

## 加载顺序
- 从**下到上**加载（高优先级覆盖低优先级）
- 通过 `/datapack` 命令或世界创建界面调整
- 顺序保存在 `level.dat` → `DataPacks`

## 安装位置
- 单人：`.minecraft/saves/<world>/datapacks/`
- 服务器：`world/datapacks/`
- 世界创建界面添加

### 自动生成（1.21.6+）
可以使用命令 `/datapack create <id> <name>` 在当前世界文件夹中自动生成一个带有 `pack.mcmeta` 和 `data/` 基础结构的目录式数据包。

## 热重载范围
| 可重载 | 不可重载 |
|--------|----------|
| 函数、进度、配方、战利品表、谓词、物品修饰器、标签 | 世界生成、维度、附魔、唱片机、对话、变种、试炼刷怪笼 |

## Safe Mode
数据包损坏导致世界无法加载时，游戏提示启用安全模式（仅原版）。

## 命名约束
合法字符：`a-z`, `0-9`, `_`, `-`, `.`, `/`。约定使用 `snake_case`。`minecraft` 命名空间用于覆盖原版。
