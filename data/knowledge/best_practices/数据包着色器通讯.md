# 数据包↔着色器通讯（粒子通道）

> 数据包→着色器的唯一可靠方案。

## 原理
```
数据包: /particle entity_effect{color:[R,G,B,A]} ~ ~ ~
  (特定 alpha 值标记为"数据粒子")
    ↓
顶点着色器: 检测 alpha 区间 → 重定向到屏幕角落
    ↓
后期着色器: 读取屏幕角落像素 → 获得 RGB 数据
```

## 数据包端
```mcfunction
# alpha=0.114 标记为数据粒子
execute as @a at @s run particle entity_effect{color:[1.0,0.5,0.0,0.114]} ~ ~ ~
```

## 关键细节
- alpha 范围检测：`Color.a > 0.113 && Color.a < 0.115`（浮点精度）
- 只用 `entity_effect`，`tinted_leaves` 的 alpha 固定为 1.0
- 屏幕角落 2×2 像素足以传输数据
- 需要"华丽"画质（`transparency.json` 后期管线）
