# 数据结构

## 队列（FIFO）
```mcfunction
# 入队
data modify storage q:data list append value "item1"

# 出队
data modify storage q:data deque set from storage q:data list[0]
data remove storage q:data list[0]

# 长度
execute store result score #len tmp run data get storage q:data list
```

## 栈（LIFO）
```mcfunction
# 入栈
data modify storage s:data list prepend value "item1"

# 出栈（[-1] 是最后一个元素）
data modify storage s:data pop set from storage s:data list[-1]
data remove storage s:data list[-1]
```

## 实体树（OOP 通过乘客）
```mcfunction
# 根 = item_display（可插值）
summon item_display ~ ~ ~ {Tags:["Camera"],teleport_duration:5,Passengers:[
  {id:"item",PickupDelay:32767,Age:-32768,Item:{id:"music_disc_11",count:1,components:{"item_model":"air"}},Tags:["Ptr","CameraEntity"]}
]}

# 导航：执行乘客→访问指针→on origin→获取目标
execute on passengers if entity @s[tag=Ptr] on origin run say Found!
```

## 多 tick 处理（反卡顿）
```mcfunction
# 将大操作拆分到多个 tick
execute if score $remaining bs.data matches 1.. run schedule function mypack:process_batch 1t

# 或用 limit 参数限制每 tick 步数
```

## 回调模式
```mcfunction
# 通过 storage 传递回调命令
data modify storage namespace:io ctx set value {run:"say Hello",on_finished:"say Done"}
function #mypack:iterate with storage namespace:io ctx

# 宏内执行：
$execute $(run)
```
Lambda 分数（回调上下文）：`$module.var namespace.lambda`
