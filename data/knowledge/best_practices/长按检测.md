# 检测长按开始/结束/持续

## 半减除法检测按键状态

用一个计分板变量检测按键/触发的长按开始、持续中、释放：

```mcfunction
# state 变量：0=空闲, 2=刚按下, 3=按住, 1=刚释放
scoreboard objectives add state dummy
scoreboard players set 2 const 2  # 除数

# tick 函数——状态衰减
scoreboard players operation @s state /= 2 const

# 事件触发时加 4
scoreboard players add @s state 4

# 检测
execute if score @s state matches 2 run say 刚按下！
execute if score @s state matches 3 run say 按住中...
execute if score @s state matches 1 run say 刚释放！
```

### 状态转移图
```
0 → (+4) → 2（上升沿）→ (/2) → 3（激活）→ (/2) → 3 → ... → (/2) → 1（下降沿）→ (/2) → 0（空闲）
```

### 防抖变体（+6）
加 6 而非 4 时，3=按下, 4~5=防抖保持, 1=释放, 2=过渡状态。

### 典型应用场景
- 检测玩家长按右键（如蓄力技能）
- 检测玩家按下/释放某个按键
- 检测持续状态（如持续按住时每tick执行某操作）
