# 字段驱动命名与方法边界

来源：`data/archive/inbox/20260606_141500.md`、`data/archive/inbox/怎么让命名保持干净.md`

这是一套推荐性 mcfunction 组织规范。它不由游戏强制检查，目标是让同一概念在
函数、计分板、storage、实体标签和对象数据中保持一致，并明确方法调用边界。

## 核心原则

1. 简短优先，但不能因为缩写产生歧义。
2. 同一字段在不同存储位置使用相同核心名称。
3. 没有真实结构冲突时，不增加多余层级。
4. 公共方法、私有方法和中间过程具有不同调用权限。
5. 临时变量跨越普通公共方法调用后，应视为内容未知。

## 字段

字段是一组命名和数据形式的约定，类似类或接口。任何符合约定的数据、实体或
方块都可视为该字段的对象。

以 `projectile` 为例：

```text
score(@s projectile)
score(projectile <namespace>)
storage(<namespace>:io projectile)
storage(<namespace>:data projectile)
tag(<namespace>.projectile)
function <namespace>:projectile/create
```

实体 tag 不具有资源位置式命名空间隔离，因此必须手动添加命名空间前缀。

## 属性与继承

- **属性**：字段的一部分数据，例如 `projectile.speed`、`projectile.life`。
- **继承**：字段的一种完整特殊类型，例如 `projectile.fire`、`projectile.ice`。

同一个名称不应同时表达属性和继承。

在记分板、tag 和临时 IO 中，字段本身及其子字段可以使用短名称。长期嵌套 NBT
中若字段值与子字段冲突，应增加专用层：

```text
# 冲突：test 不能同时是数值和 compound
storage(<namespace>:data test) 1b
storage(<namespace>:data test.a) 2b

# 解决
storage(<namespace>:data test.value) 1b
storage(<namespace>:data test.a) 2b
```

父类型属性与多个继承类型冲突时，可仅在长期结构中增加 `default`：

```text
storage(<namespace>:data character.default.health)
storage(<namespace>:data character.knight.health)
storage(<namespace>:data character.mage.health)
```

## 方法与中间过程

```text
projectile/create                 公共方法，可由字段外调用
projectile/create/validate        create 的中间过程
projectile/create/write_data      create 的中间过程
projectile/__validate             字段内共享的私有方法
```

- 公共方法是稳定 API。
- 中间过程只属于其直接父方法，不应被其他方法调用。
- 多个方法需要共享逻辑时，将中间过程提升为私有方法。
- 私有方法可与调用方共享临时变量，但不得覆盖调用方后续仍需使用的值。

## 特殊标记

特殊标记表达调用约定，不代表新的业务名称。判断冲突时应忽略标记：

```text
__tick__       自动方法，由 tick、进度、附魔等游戏入口调用
__validate     私有方法，仅供当前字段内部调用
__id__         长期变量，需要跨 tick 保存且不应随意修改
```

`__tick__`、`__tick` 和 `tick` 应被视为同一业务名称；若同时存在，它们的功能
必须一致，通常只允许增加一层转发。

## 方法契约

方法输入默认只读。需要修改输入或产生其他副作用时，必须在头文档中说明：

```mcfunction
#> projectile/create
#   创建投射物
# @input
#   storage <namespace>:io projectile
# @output
#   新创建的投射物；会清空 io projectile
```

## 临时变量失效规则

```text
score(#temp <namespace>)
score(@s <namespace>)
storage(<namespace>:io temp.projectile)
tag(<namespace>.this)
tag(<namespace>.init)
```

调用普通公共方法后，即使这些值物理上仍然存在，也应视为内容未知，不得继续读取。
这样公共方法可以自由使用共享临时空间，而不会形成隐式耦合。

需要跨公共方法传值时：

1. 使用显式命名的输入，如 `storage <namespace>:io projectile`。
2. 在方法契约中声明是否修改输入。
3. 存在递归或嵌套调用时，使用变量栈，避免共享位置被覆盖。
4. 若调用只是当前方法内部的共享过程，将其定义为私有方法。

## 适用范围

这套规则适合中大型数据包和多人协作项目。小型一次性函数不必机械套用全部
层级，但仍应保持字段名称一致，并明确哪些函数属于公共 API。
